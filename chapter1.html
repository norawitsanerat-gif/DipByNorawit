CHAPTER OVERVIEW

เราจะเรียนอะไรบ้างในบทนี้?

บทนี้ปูพื้นฐานของ Digital Image Processing — ตั้งแต่ภาพดิจิทัลคืออะไร ไปจนถึงความลึกของสี

วิธีเรียนที่แนะนำกด Next ไปทีละสไลด์ ลองกดปุ่มใน Diagram ดู และอย่าลืมทำ Quiz ตอนท้ายเพื่อตรวจความเข้าใจ

FUNDAMENTAL CONCEPTS

ภาพดิจิทัล คืออะไร?

นิยามจริงจากตำรา: ภาพ คือฟังก์ชัน 2 มิติ f(x, y) — ฟังดูยากแต่จริง ๆ แค่ 2 อย่าง

อ่านสูตร f(x, y) แบบจับมือ
f(x, y)

อ่านว่า: "ภาพ = ค่าความเข้ม ณ ตำแหน่ง (x, y)"

📍 x, y = ตำแหน่ง — พิกัด (แกน x แนวนอน, แกน y แนวตั้ง) บอกว่าจุดนี้อยู่ตรงไหนของภาพ
🎨 ค่าของ f = ความเข้ม — ตรงตำแหน่งนั้นมีความสว่าง/ระดับเทา (intensity / gray level) เท่าไร

แต่ละช่อง = 1 ตำแหน่ง (x, y) ที่มีค่าความเข้มของตัวเอง — นี่คือภาพดิจิทัล

เมื่อไหร่ถึงเรียกว่า "ดิจิทัล"

เมื่อทั้ง x, y (ตำแหน่ง) และ ค่าความเข้ม ถูกแบ่งเป็นค่าจำกัด (discrete / finite) — ไม่ต่อเนื่องเป็นเส้นเรียบอีกต่อไป → เรียกว่า ภาพดิจิทัล

ประกอบด้วยอะไร?

องค์ประกอบจำนวนจำกัด (finite number of elements) — แต่ละตัวมี ตำแหน่ง (location) และ ค่า (value) ของตัวเอง เรียกว่า พิกเซล (pixel)

จำแบบนี้ภาพ = f(x, y) · x, y = ตำแหน่ง · f = ความเข้ม · ค่าไม่ต่อเนื่อง = ดิจิทัล

FUNDAMENTAL CONCEPTS

พิกเซล (Pixel)

องค์ประกอบของภาพดิจิทัล — มีหลายชื่อเรียก แต่ที่ใช้กันแพร่หลายที่สุดคือ Pixel

พิกเซลเดียว เก็บข้อมูล 2 อย่าง
📍 ตำแหน่ง (location) — พิกเซลอยู่ตรงไหนของภาพ (พิกัด x, y)
🎨 ค่า (value) — ตรงจุดนี้มีความเข้ม/สีเท่าไร

ภาพดิจิทัล = องค์ประกอบจำนวนจำกัด (finite elements) — แต่ละตัวมีตำแหน่ง + ค่า

ชื่อเรียกเดียวกัน 4 แบบ

• Picture elements
• Image elements
• Pels
• Pixels ← คำที่ใช้กันแพร่หลายที่สุด

ซูมเข้าไปดู

ถ้าซูมภาพดิจิทัลเข้าไปเรื่อย ๆ จะเห็นตารางสี่เหลี่ยมเล็ก ๆ เรียงกันเป็นแถวและหลัก — นั่นคือพิกเซล

Exam Tipจำชื่อเรียกทั้ง 4: picture elements · image elements · pels · pixels — ข้อสอบอาจถามว่าคำไหนใช้บ่อยที่สุด → Pixel

FUNDAMENTAL CONCEPTS

Digital Image Processing คืออะไร?

นิยามจากตำรา: DIP = การประมวลผลภาพดิจิทัล โดยใช้คอมพิวเตอร์ดิจิทัล

อ่านนิยามแบบจับมือ
"Digital Image Processing = การประมวลผล
ภาพดิจิทัล ด้วย คอมพิวเตอร์ดิจิทัล"
1. ภาพต้องเป็น ดิจิทัล ก่อน (ประกอบด้วยพิกเซลจำนวนจำกัด)
2. เอามาให้ คอมพิวเตอร์ จัดการ/แก้ไข/วิเคราะห์
จัดการ

ปรับแต่งภาพ เช่น หมุน ขยาย ย่อ ครอบตัด

แก้ไข

ปรับคุณภาพ เช่น ความสว่าง ความคมชัด ลด noise

วิเคราะห์

ดึงข้อมูลจากภาพ เช่น หาวัตถุ อ่านตัวอักษร นับจำนวน

พูดง่าย ๆDIP คือการเอา "ภาพ" มาให้คอมพิวเตอร์ช่วยทำให้ดีขึ้น หรือช่วย "เข้าใจ" ว่าภาพมีอะไรอยู่

WHY DIP?

Vision กับ EM Spectrum

การมองเห็นเป็นประสาทสัมผัสที่ล้ำที่สุดของมนุษย์ — แต่ตาคนก็ยังเห็นได้จำกัด

ตาคน vs เครื่องจักร
👁️ ตาคน — จำกัดอยู่ที่แถบแสงที่มองเห็น (visual band)
รังสีแกมมา เอกซเรย์ UV อินฟราเรด คลื่นวิทยุ

เครื่องจักร (imaging machines) ครอบคลุม EM spectrum เกือบทั้งหมด — ตั้งแต่รังสีแกมมา → คลื่นวิทยุ

ภาพสำคัญที่สุดต่อการรับรู้

Vision เป็นประสาทสัมผัสที่ล้ำที่สุดของมนุษย์ — ภาพจึงมีบทบาทสำคัญที่สุดในการรับรู้ของคนเรา

ภาพจากแหล่งที่ตาคนมองไม่เห็น

• ภาพอัลตราซาวด์ (Ultrasound)
• ภาพจากกล้องจุลทรรศน์อิเล็กตรอน
• ภาพที่คอมพิวเตอร์สร้างขึ้น (computer-generated)

จำแบบนี้ตาเห็นแค่ visual band แต่เครื่องจักรเห็นได้เกือบทั้ง EM spectrum → DIP จึงใช้งานได้กว้างมาก

APPLICATIONS

สาขาที่ใช้ DIP 1 — คลื่น EM

จากตำรา Gonzalez — เครื่องจักร "มองเห็น" คลื่นได้ตั้งแต่แกมมาไปจนถึงวิทยุ

รังสีแกมมา (Gamma-ray)

ภาพจากนิวเคลียร์/การแพทย์นิวเคลียร์

เอกซเรย์ (X-ray)

การแพทย์ · ตรวจสอบสินค้า (baggage)

UV / Visible / IR

ภาพถ่าย กล้องวงจรปิด ภาพอินฟราเรดจากดาวเทียม

Multi-spectral / Microwave

ภาพพายุเฮอร์ริเคนจากดาวเทียม · สำรวจธรณี/น้ำมัน

Exam Tipลำดับแถบคลื่น: Gamma → X-ray → UV → Visible → IR → Microwave → Radio — ยิ่งเลขความถี่สูง (แกมมา) ยิ่งเป็นคลื่นสั้น พลังงานสูง

APPLICATIONS

สาขาที่ใช้ DIP 2 — นอก EM spectrum

นอกจากคลื่น EM ยังมีเสียง อัลตราซาวด์ อิเล็กตรอน และภาพจากคอมพิวเตอร์

Radio / Acoustic / Ultrasound

ดาราศาสตร์วิทยุ · ภาพเสียงสำรวจธรณี/น้ำมัน (hundreds Hz → millions Hz) · อัลตราซาวด์การแพทย์

Electron microscopy

กล้องจุลทรรศน์อิเล็กตรอน — เห็นโครงสร้างระดับนาโน

Computer-generated images

ภาพที่สร้างจากคอมพิวเตอร์กราฟิก (ไม่ใช่กล้องถ่าย)

บันเทิง & ความปลอดภัย

ภาพยนตร์/เกม (CGI) · กล้องวงจรปิด · ภาพนิติวิทยาศาสตร์ (law enforcement)

อุตสาหกรรม

ตรวจสอบชิ้นงานโรงงาน (manufacturing inspection) — หาชิ้นส่วนบกพร่องอัตโนมัติ

Exam Tipภาพ 1 ภาพใน DIP มาจากได้หลายแหล่ง: กล้อง EM · เสียง/อัลตราซาวด์ · อิเล็กตรอน · คอมพิวเตอร์กราฟิก

PROCESSING LEVELS · 1/3

ระดับต่ำ (Low-level)

งานพื้นฐาน (primitive operations) — เตรียมภาพก่อนนำไปใช้ต่อ

ทำอะไร?

image preprocessing 3 งานหลัก (จากตำรา):

🔇 ลด noise — ลบจุดรบกวน (salt & pepper, grain)
🌗 ปรับ contrast — ทำให้ภาพมืด/สว่าง อ่านง่ายขึ้น
🪄 image sharpening — ทำให้ขอบภาพคมชัดขึ้น
Exam TipLow-level = preprocessing → จำ 3 คำ: ลด noise · ปรับ contrast · sharpening

PROCESSING LEVELS · 2/3

ระดับกลาง (Mid-level)

เริ่มเข้าใจ "วัตถุ" ในภาพ — แบ่งส่วน อธิบาย และจำแนก

✂️ Segmentation — แบ่งภาพออกเป็นส่วน/วัตถุ (partitioning into regions or objects)
📋 Description — อธิบายวัตถุให้อยู่ในรูปแบบที่คอมพิวเตอร์ประมวลผลต่อได้
🏷️ Classification / Recognition — จำแนกว่าแต่ละวัตถุคืออะไร
Exam TipMid-level = segmentation + description + classification — ข้อสอบถาม "งานใดเป็นระดับกลาง?" ให้ตอบกลุ่มนี้

PROCESSING LEVELS · 3/3

ระดับสูง (Higher-level)

วิเคราะห์ภาพทั้งภาพรวม — ใกล้เคียง "การคิด" แบบที่มนุษย์ใช้ตอนมองเห็น

ทำอะไร?

รวมกลุ่มวัตถุที่จดจำได้ทั้งหมด (ensemble of recognized objects) มาวิเคราะห์ร่วมกัน — เรียกว่า image analysis

ตัวอย่าง

ภาพห้องหนึ่งห้อง → จดจำ "โต๊ะ เก้าอี้ คน" แล้วเข้าใจว่ากำลังเกิดอะไรขึ้น (cognitive functions)

Exam TipHigher-level = image analysis / cognitive — สูงสุดของสายการประมวลผล

REAL EXAMPLE · THE COMPUTERIZED PROCESS

ตัวอย่าง: การอ่านตัวอักษรจากภาพ

จากตำรา: automated analysis of text — งานเดียวแต่ต้องผ่านหลายระดับการประมวลผล

PIPELINE · 5 ขั้นตอน
1📷 Acquiring — ถ่ายภาพพื้นที่ที่มีข้อความ
2✨ Preprocessing — ปรับภาพให้พร้อม
3✂️ Segmenting — ตัดแยกตัวอักษรแต่ละตัว
4🔤 Describing — อธิบายรูปร่างให้คอมพิวเตอร์เข้าใจ
5🧠 Recognition — จดจำว่าตัวอักษรคือตัวอะไร

ขั้นไหนเป็นระดับไหน

• ถ่ายภาพ + ปรับชัด → Low-level
• ตัดแยก + อธิบายรูปร่าง → Mid-level
• จดจำตัวอักษร → Higher-level

ต่อเนื่องกัน

งานจริงต้องใช้หลายระดับต่อกัน — ผลลัพธ์ของขั้นหนึ่งเป็น input ของขั้นถัดไป

จำแบบนี้อ่านตัวอักษร = acquire → preprocess → segment → describe → recognize

HISTORY · THE ORIGINS

ประวัติศาสตร์ คร่าว ๆ

จากภาพข่าวสายเคเบิลใต้น้ำในยุค 1920 จนถึงการใช้งานที่ระเบิดตัวในยุค 1980

1920
Bartlane cable picture transmission system

ระบบส่งภาพข่าวผ่านสายเคเบิลใต้น้ำระหว่าง ลอนดอน–นิวยอร์ก — ลดเวลาส่งภาพข้ามแอตแลนติกจาก มากกว่า 1 สัปดาห์ เหลือน้อยกว่า 3 ชั่วโมง

1980s
การใช้งานเทคนิค DIP ระเบิดตัว

ใช้กับงานทุกประเภทในทุกวงการ — บันเทิง, ความปลอดภัย, การแพทย์, อุตสาหกรรม, ดาวเทียม ฯลฯ

เทคนิคในยุคแรก

ภาพถูกแบ่งเป็นช่อง ๆ (still not fully digital) แล้วส่งเป็นรหัส — เป็นแนวคิดต้นทางของ DIP ที่พัฒนามาเรื่อย ๆ

ทำไมยุค 1980 สำคัญ

คอมพิวเตอร์มีพลังพอจะประมวลผลภาพได้จริงจัง + ราคาเครื่องมือถูกลง → ภาพดิจิทัลเข้าถึงทุกวงการ

Exam Tipจำตัวเลข: ต้นทศวรรษ 1920 · สายเคเบิลใต้น้ำ ลอนดอน-นิวยอร์ก · ลดเวลาจาก >1 สัปดาห์ เหลือ <3 ชั่วโมง

FUNDAMENTAL STEPS

ขั้นตอนพื้นฐาน (Fundamental Steps)

แต่ละหัวข้อคือขั้นตอนหนึ่งในสายการประมวลผลภาพ — จำ 6 ตัวนี้ให้ได้

Acquisitionถ่าย/รับภาพเข้าระบบ
Enhancementทำให้ภาพดูดีขึ้น
Restorationซ่อมภาพที่เสียหาย
Morphologicalจัดการรูปร่างวัตถุ
Compressionบีบอัดไฟล์ภาพ
Colourจัดการภาพสี
Exam Tipจำคำขึ้นต้น 6 ตัว: Acquisition · Enhancement · Restoration · Morphological · Compression · Colour — ข้อสอบอาจถามว่า "ข้อใดไม่ใช่ขั้นตอนพื้นฐาน"

FUNDAMENTAL STEP 1

Image Acquisition

การถ่าย/รับภาพเข้าระบบ — เป็นขั้นแรกของทุกสายการประมวลผล

ตัวอย่างแหล่งภาพ (Acquisition)
กล้องดิจิทัล
เครื่องสแกน
ดาวเทียม
เครื่องเอกซเรย์

ทำอะไรในขั้นนี้

นำภาพจากแหล่งต่าง ๆ (กล้อง/สแกนเนอร์/เซนเซอร์) เข้ามาเป็นข้อมูลดิจิทัลในคอมพิวเตอร์ พร้อมจัดรูปแบบให้พร้อมประมวลผลต่อ

จำแบบนี้Acquisition = "ได้ภาพมา" — ขั้นแรกสุด ไม่มีภาพก็ทำอะไรต่อไม่ได้

FUNDAMENTAL STEP 2

Image Enhancement

การทำให้ภาพ ดูดีขึ้น — ตามการรับรู้ของคนดู (ไม่ได้แก้ "ความผิดพลาด" ของกล้อง)

ปรับปรุงอะไรได้บ้าง
☀️ ความสว่าง — ภาพมืดไป → ปรับให้สว่างขึ้น
🎚️ Contrast — สีดูจาง ๆ → เพิ่มความต่างให้ชัด
🔍 ความคมชัด — ภาพเบลอ → ทำให้ขอบชัดขึ้น
🌊 ลด noise — จุดเกรนรบกวน → ทำให้เรียบเนียนขึ้น

ขึ้นกับคนดู

Enhancement ค่อนข้าง "อัตวิสัย" — ภาพแบบไหน "ดี" ขึ้นอยู่กับความชอบของคนดูแต่ละคน

Exam TipEnhancement = ทำให้ดูดีขึ้น · Restoration = ซ่อมภาพที่เสีย (ใช้แบบจำลอง) — ข้อสอบชอบเทียบสองตัวนี้

FUNDAMENTAL STEP 3

Image Restoration

การ ซ่อมแซมภาพที่เสียหาย — ใช้แบบจำลองความเสียหาย (model) มาช่วยกู้คืน

ภาพเสียหายแบบไหน → ซ่อมยังไง
🌫️ เบลอ (blur) — จากกล้องสั่น → ปรับให้คมกลับมา
🌧️ มี noise — จากเซนเซอร์ → ลดสัญญาณรบกวน
✂️ ขาดหาย — ภาพเก่าชำรุด → ฟื้นฟูส่วนที่เสีย

ต่างจาก Enhancement ยังไง

Restoration ใช้ แบบจำลองความเสียหาย เพื่อคืนภาพให้ใกล้ต้นฉบับ — เป็นการแก้ปัญหาที่มีหลักการชัดเจน ต่างจาก Enhancement ที่เน้นความสวยตามคนดู

ใช้กับภาพเก่า

ซ่อมภาพถ่ายเก่า ภาพประวัติศาสตร์ที่ซีดจาง/มีรอยขีดข่วน ให้กลับมาดูชัดอีกครั้ง

จำแบบนี้Restoration = ซ่อมของเสียให้กลับสภาพเดิม (ใช้ model) · Enhancement = ทำให้ดูดีขึ้น

FUNDAMENTAL STEP 4

Morphological Processing

การจัดการ รูปร่างของวัตถุ ในภาพ — เช่น ทำให้โครงสร้างหนา/บางลง

ตัวอย่างการจัดการรูปร่าง
⬛→🟪

ขยายรูปร่าง (dilate)

🟪→⬛

ย่อรูปร่าง (erode)

ใช้บ่อยกับภาพขาวดำเพื่อลบจุดเล็ก ๆ หรือเชื่อมรอยขาดของเส้น

นำไปใช้ทำอะไร

• ลบจุดรบกวนเล็ก ๆ ในภาพขาวดำ
• เชื่อมเส้นที่ขาดให้ต่อกัน
• แยกวัตถุที่ติดกันออกจากกัน
• หาโครงร่าง (skeleton) ของวัตถุ

จำแบบนี้Morphological = เปลี่ยน "รูปร่าง" ของวัตถุในภาพ (หนา/บาง/ต่อ/ขาด)

FUNDAMENTAL STEP 5

Image Compression

การ บีบอัดขนาดไฟล์ภาพ ให้เล็กลง — เพื่อประหยัดพื้นที่และแบนด์วิดท์

ทำไมต้องบีบอัด
💾 ประหยัดพื้นที่ — เก็บภาพได้มากขึ้นในดิสก์/คลาวด์
🚀 ส่งเร็วขึ้น — ไฟล์เล็กลง → โหลด/แชร์เร็วขึ้น
📡 ใช้แบนด์วิดท์น้อยลง — ส่งภาพผ่านเน็ตได้เยอะขึ้น

แลกมาด้วยอะไร

การบีบอัดอาจลดคุณภาพภาพลงบ้าง (โดยเฉพาะแบบ lossy) — ต้องหาจุดสมดุลระหว่างขนาดไฟล์กับคุณภาพ

ไฟล์ที่เจอบ่อย

JPEG (lossy บีบอัดสูง), PNG (lossless คมชัด), GIF (เหมาะภาพกราฟิก/แอนิเมชัน)

จำแบบนี้Compression = ทำให้ไฟล์ภาพเล็กลง → ประหยัดพื้นที่ + ส่งเร็วขึ้น

FUNDAMENTAL STEP 6

Colour Image Processing

การจัดการ ภาพสี — เพราะสีคือข้อมูลสำคัญของภาพ

งานเกี่ยวกับสี
🎨 ปรับสมดุลสี — แก้ภาพเหลือง/เขียวผิดเพี้ยน
🌗 แปลงสีเป็นเทา — RGB → grayscale เพื่อลดข้อมูล
🔍 แยกรายละเอียดด้วยสี — หาวัตถุจากสี (เช่น หาใบหน้าจากสีผิว)

สีที่คอมพิวเตอร์ใช้

ระบบสี RGB (แดง-เขียว-น้ำเงิน) เป็นพื้นฐานของภาพดิจิทัลสี — จะเรียนลึกในสไลด์ถัดไป

Exam TipColour Processing = เกี่ยวกับ "สี" ของภาพ ไม่ใช่ความคมชัดหรือขนาดไฟล์

BITMAP

Bitmap คืออะไร?

นิยามจากตำรา: ตารางสี่เหลี่ยม (rectangular mesh) ของเซลล์ที่เรียกว่าพิกเซล — แต่ละพิกเซลเก็บค่าสี

คุณสมบัติหลัก 2 อย่าง (characterised by only two parameters)
1️⃣ จำนวนพิกเซล — กว้าง × สูง เช่น 397 × 294 จากตัวอย่างตำรา
2️⃣ ความลึกของสี (color depth) — ข้อมูลต่อพิกเซล เช่น แต่ละพิกเซลมีระดับเทาจาก 256 ค่าที่เป็นไปได้

Bitmap เรียงตัวแนวนอน-แนวตั้งเสมอ และพิกเซลถือว่าเป็นสี่เหลี่ยมจัตุรัส (โดยทั่วไป)

ภาพแบบ Bitmap

รูปถ่าย ภาพสแกน รูปจากอินเทอร์เน็ตส่วนใหญ่เป็น bitmap — ถ้าซูมเข้าไปจะเห็นช่องพิกเซลชัดเจน

ตัวอย่างจากตำรา

Bitmap กว้าง 397 พิกเซล × สูง 294 พิกเซล — แต่ละพิกเซลเก็บค่าระดับเทาจาก 256 ระดับที่เป็นไปได้

Exam TipBitmap มีคุณสมบัติหลัก 2 อย่าง = จำนวนพิกเซล + ความลึกของสี (color depth)

COLOR DEPTH

ความลึกของสี (Color Depth)

จำนวนบิตที่ใช้เก็บสีต่อ 1 พิกเซล — ยิ่งบิตเยอะ ยิ่งมีสีให้เลือกมาก

1 bit vs 8 bit — ตัวอย่างจากตำรา
1 bit

ข้อมูลน้อยที่สุดต่อพิกเซล — 2 ค่า: 0 = ดำ, 1 = ขาว · ภาพขาวดำ (monochrome)

8 bit grayscale

1 ไบต์ต่อพิกเซล = 256 ระดับ (28) — โดยธรรมเนียม 0 = ดำ, 255 = ขาว, 127 = เทา 50%

ระดับเทา (Grayscale)

ภาพ 8 bit โทนเทา เก็บระดับความเข้ม 0–255 — เหมาะกับเอกซเรย์ ภาพสแกนเอกสาร

คำนวณจำนวนสี

จำนวนสี = 2บิตต่อพิกเซล — 1 bit → 2 สี · 8 bit → 256 สี · 24 bit → 16.7 ล้านสี

Exam Tip1 bit = ขาวดำล้วน (0=ดำ, 1=ขาว) · 8 bit = เทา 256 ระดับ (0=ดำ, 255=ขาว) — จำตัวเลข 2 ตัวนี้ให้แม่น

COLOR DEPTH · RGB

24/32 bit RGB และ Indexed Color

จากสีจริง 16.7 ล้านสี ไปจนถึงการประหยัดพื้นที่ด้วยตารางสี

RGB 24 bit · 32 bit — ช่องสี
24 bit RGB

แดง (R) + เขียว (G) + น้ำเงิน (B) อย่างละ 8 bit = 24 bit → 224 ≈ 16.7 ล้านสี (สีจริง)

32 bit RGBA

24 bit RGB + ช่อง Alpha (A) 8 bit สำหรับความโปร่งใส = 32 bit

RGB COLOR CUBE · สีทุกสีคือจุดในลูกบาศก์

RGB space: สีใด ๆ = จุดใน color cube ที่มีแกน r, g, b — พื้นฐานของ computer graphics

Indexed Color (8 bit / 4 bit)

วิธีเก็บภาพสีที่ประหยัดกว่า (ไม่ต้องใช้ 3 ไบต์ต่อพิกเซล) — ใช้ ตารางสี (color palette / color table) พิกเซลเก็บแค่ดัชนีชี้ในตาราง

สรุปความลึกสีที่พบบ่อย

• 1 bit — ขาวดำล้วน
• 8 bit — เทา 256 ระดับ
• 16 bit RGB — 5-5-5 + Alpha 1 บิต
• 24 bit — RGB สีจริง 16.7 ล้านสี
• 32 bit — RGB + Alpha โปร่งใส
• 8/4 bit indexed — ใช้ palette

16 bit RGB

ระบบตรง: แดง/เขียว/น้ำเงิน อย่างละ 5 บิต + Alpha 1 บิต = 16 บิต

32 bit RGB

เหมือน 24 bit + ช่อง Alpha 8 บิต — ใช้ทำ masked areas / ความโปร่งใส

Exam Tip24 bit = 3 ช่อง × 8 bit · 32 bit = 24 bit + Alpha · 16 bit = 5-5-5 + Alpha 1 · Indexed = ใช้ palette ประหยัดพื้นที่
