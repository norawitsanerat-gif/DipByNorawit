SEGMENTATION

Segmentation คืออะไร?

แบ่งภาพออกเป็นส่วน ๆ — แยก "วัตถุ" (object) ออกจาก "พื้นหลัง" (background)

ก่อน → หลัง Segmentation

ภาพ grayscale (พิกเซล)

→

binary: ขาว = object, ดำ = background

Objectสิ่งที่สนใจ — เช่น วัตถุชิ้นงาน, ตัวหนังสือ, เซลล์
Backgroundส่วนที่เหลือรอบ ๆ

อยู่ตรงไหนของ Pipeline?

Camera → Enhancement (บท 4) → Filter (บท 5) → Threshold/Segmentation (บทนี้) → Contour → Detection

ทำไมต้องแยก?

ก่อนจะนับ/วัด/ตรวจจับอะไร ต้องรู้ก่อนว่า "ตรงไหนคือตัววัตถุ" — segmentation คือก้าวแรก

เทคนิคสอบSegmentation = แยก object/background · วิธีง่ายสุด = Threshold (แบ่งด้วยค่าความเข้ม)

GLOBAL THRESHOLD

Global Threshold — ขีดค่าเดียวทั้งภาพ

เลือกค่าขีด (threshold) หนึ่งค่า — พิกเซลต่ำกว่าค่าขีดไปฝั่งหนึ่ง สูงกว่าไปอีกฝั่ง

ตัวอย่าง: threshold = 128 
ret, binary = cv2.threshold(
    gray, 128, 255, cv2.THRESH_BINARY)

# พิกเซล 0–128    → 0   (ดำ)
# พิกเซล 129–255  → 255 (ขาว)
threshค่าขีด (ที่นี่ 128) — ตัวเลขเดียวใช้ทั้งภาพ = "Global"
maxvalค่าที่ให้เมื่อผ่าน (255 = ขาว)

ผลลัพธ์

ภาพ binary (2 ค่า: 0 กับ 255) — ง่ายสุด เหมาะกับภาพแสงสม่ำเสมอ พื้นหลังชัด

จุดอ่อน

ภาพแสงไม่สม่ำเสมอ → ขีดเดียวตัดไม่ได้ทุกส่วน (เจอในสไลด์ 7)

เทคนิคสอบGlobal = 1 ค่าขีดทั้งภาพ · cv2.threshold(gray, 128, 255, cv2.THRESH_BINARY)

THRESHOLD MODES 1–2

THRESH_BINARY / THRESH_BINARY_INV

สองโหมดที่เจอบ่อยสุด — ต่างกันแค่ "กลับด้าน" สีขาว-ดำ

โหมดต่ำกว่า thresholdสูงกว่า thresholdผล
THRESH_BINARY0 (ดำ)maxval (ขาว)วัตถุสว่าง → ขาว
THRESH_BINARY_INVmaxval (ขาว)0 (ดำ)กลับด้าน: วัตถุสว่าง → ดำ
ตัวอย่าง: พิกเซล 100 กับ 150 (thresh 128) 
BINARY      : 100 → 0 · 150 → 255
BINARY_INV  : 100 → 255 · 150 → 0
INVใช้เมื่อวัตถุ "มืดกว่า" พื้นหลัง — กลับให้วัตถุเป็นขาวก่อนทำงานต่อ
จำINV = INVerse = เอาสีสลับกัน
เทคนิคสอบถาม "object มืด background สว่าง" → ใช้ BINARY_INV เพื่อให้ object เป็นขาว

THRESHOLD MODES 3–5

TRUNC / TOZERO / TOZERO_INV

อีก 3 โหมดที่ไม่ได้ให้แค่ 0/255 — เก็บค่าความเข้มเดิมไว้บางส่วน

โหมดต่ำกว่า threshสูงกว่า thresh
THRESH_TRUNCค่าเดิมถูก "ตัด" ให้เท่ากับ thresh (ล็อกค่าบน)
THRESH_TOZEROกลายเป็น 0ค่าเดิม (คงไว้)
THRESH_TOZERO_INVค่าเดิม (คงไว้)กลายเป็น 0
ตัวอย่าง thresh = 128 
ค่าเดิม 100 / 150  →
TRUNC        : 100 → 100 · 150 → 128 (ตัดลง)
TOZERO       : 100 → 0   · 150 → 150
TOZERO_INV   : 100 → 100 · 150 → 0
TRUNC"ตัด" ค่าสูงเกินให้เท่ากับขีด — ใช้ลบ highlight
TOZERO"เก็บของที่ผ่านขีด โละของที่ต่ำกว่า" → เป็น 0

WORKED EXAMPLE

5 โหมด ในภาพแสงไล่ระดับ

ตัวอย่างจาก PDF — ภาพพื้นขาว + ตัวหนังสือดำ + แสงไล่ระดับ (gradient) ทดสอบทุกโหมด

สร้างภาพทดสอบ 
import cv2, numpy as np
h, w = 400, 600
img = np.ones((h, w), np.uint8) * 255
cv2.putText(img, "IMAGE PROCESSING", (80, 180),
    cv2.FONT_HERSHEY_SIMPLEX, 1.5, 0, 3)
gradient = np.tile(np.linspace(1.0, 0.4, w), (h, 1))
img_bad = (img * gradient).astype(np.uint8)

ปัญหา

ฝั่งซ้ายสว่าง ฝั่งขวามืด (แสงไม่สม่ำเสมอ) — ขีดเดียว (global) ตัดไม่ได้ทั้งภาพ

ลองทุกโหมด

for t in [128, 192, 220]:
    _, b  = cv2.threshold(img_bad, t, 255,
                          cv2.THRESH_BINARY)
    _, bi = cv2.threshold(img_bad, t, 255,
                          cv2.THRESH_BINARY_INV)
adaptive = cv2.adaptiveThreshold(img_bad, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY, 11, 2)
ผล: global ตัดฝั่งขวาพัง (มืดเกิน) · adaptive ผ่านทุกตำแหน่ง — ไปดูสไลด์ถัดไป

WHY ADAPTIVE?

ปัญหาของ Global Threshold

ภาพแสงไม่สม่ำเสมอ — ขีดเดียวไม่พอ จะตัดพลาดบางส่วนของภาพเสมอ

ภาพแสงไล่ระดับ: สว่างซ้าย → มืดขวา
ขีดสูง (220)ฝั่งซ้ายตัดถูก แต่ฝั่งขวา (มืดกว่า 220 ทั้งหมด) กลายเป็นดำหมด
ขีดต่ำ (128)ฝั่งขวาตัดได้ แต่ฝั่งซ้าย (สว่าง) ตัวหนังสือหายไปกับพื้นขาว
ขีดกลาง (192)ทั้งสองฝั่งพังครึ่ง ๆ — ไม่มีค่าไหนใช้ได้ทั้งภาพ

เกิดขึ้นจริงที่ไหน?

สแกนเอกสารเงาตก · ถ่ายรูปมุมห้อง · ภาพกลางแจ้งแดดส่องบางส่วน — แสงไม่เท่ากันทั่วภาพ

ทางออก

Adaptive Threshold (ขีดเปลี่ยนตามตำแหน่ง) หรือ Otsu (หาขีดที่ดีที่สุดอัตโนมัติ)

เทคนิคสอบโจทย์ "แสงไม่สม่ำเสมอ / gradient / เงา" → ต้อง Adaptive — global จะตัดพลาด

ADAPTIVE THRESHOLD

Adaptive Threshold — ขีดแบบ Local

ไม่ใช้ขีดเดียว — คำนวณขีดใหม่ทุกตำแหน่งจาก neighborhood (sliding window) รอบพิกเซล

หลักการ
1เลื่อน window (kernel) ไปทุกพิกเซลเหมือน filter
2หาค่า threshold ของจุดนั้นจากค่าภายใน window (เฉลี่ย/Gaussian)
3เปรียบเทียบพิกเซลกลางกับขีดเฉพาะที่ → 0 หรือ 255
adaptive = cv2.adaptiveThreshold(
    img_bad, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY, 11, 2)

ขีดปรับตามแสง

ฝั่งสว่างได้ขีดสูง ฝั่งมืดได้ขีดต่ำ — ทุกตำแหน่งตัดถูกต้องแม้แสงไม่เท่ากัน

ใช้กับงาน

สแกนเอกสาร, OCR, ภาพถ่ายแสงไม่สม่ำเสมอ — งานที่ global ตัดไม่ได้

เทคนิคสอบAdaptive = threshold เปลี่ยนตาม neighborhood (local) · ใช้ ADAPTIVE_THRESH_GAUSSIAN_C

PARAMETERS

อ่านพารามิเตอร์ — 11 และ 2

ตัวเลข 2 ตัวสุดท้ายในโค้ดคืออะไร — อ่านทีละตัว (จากตัวอย่างใน PDF)

โค้ดเต็ม 
cv2.adaptiveThreshold(gray, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY, 11, 2)
grayภาพ grayscale อินพุต
255maxValue — พิกเซลที่ผ่านจะได้ 255 (ขาว)
GAUSSIAN_Cวิธีคำนวณขีด: ถ่วงน้ำหนักแบบ Gaussian (ไม่ใช่ค่าเฉลี่ยธรรมดา)
THRESH_BINARYโหมดผลลัพธ์ (ผ่าน = 255, ไม่ผ่าน = 0)
11blockSize — ขนาด window (11×11 พิกเซล) ใช้คำนวณขีดเฉพาะที่
2C — ค่าคงที่ลบออกจากขีด (ปรับความไว: ยิ่งมาก ยิ่งตัดง่าย)

blockSize = 11

ยิ่งใหญ่ ยิ่ง "มองไกล" (ขีดเนียน) แต่ช้า · ต้องเป็นเลขคี่

C = 2

ลบออกจากค่าเฉลี่ยของ window — กัน noise ถูกตัดเป็นขาวทั้งที่จริงไม่ใช่

เทคนิคสอบจำคู่ท้าย: 11 = window 11×11 (เลขคี่) · 2 = ค่าคงที่ C ที่ลบจาก threshold

OTSU THRESHOLD

Otsu — Threshold อัตโนมัติ

ให้คอมพิวเตอร์หาค่าขีด "ที่ดีที่สุด" ให้เอง — ไม่ต้องเดา threshold ด้วยมือ

หลักการ
1ดู histogram ของภาพ (การกระจายค่าพิกเซล)
2ลองทุกค่าขีดที่เป็นไปได้ 0–255
3เลือกค่าที่แยก 2 กลุ่ม (object/background) ได้ "ห่างกันที่สุด"
ret, binary = cv2.threshold(gray, 0, 255,
    cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print("Threshold =", ret)   # ค่าขีดที่หาได้

ไม่ต้องเดา thresh

ส่ง 0 ไปแทน threshold ได้เลย — Otsu คำนวณให้ แล้วคืนค่าผ่านตัวแปร ret

histogram แยก 2 กลุ่ม

Otsu เก่งเมื่อ histogram มี 2 ยอด (bimodal) — object กับ background คนละช่วงค่า

เทคนิคสอบOtsu = หา threshold อัตโนมัติ · ใช้ cv2.THRESH_BINARY + cv2.THRESH_OTSU · เหมาะ histogram 2 ยอด

COMPARISON

เปรียบเทียบ 3 วิธี

Global vs Adaptive vs Otsu — เลือกให้ถูกกับสภาพภาพ

วิธีขีดเหมาะกับจุดอ่อน
Global1 ค่าทั้งภาพแสงสม่ำเสมอ พื้นหลังชัดแสงไม่เท่ากัน → ตัดพลาด
Adaptiveเปลี่ยนตามตำแหน่ง (local)แสงไม่สม่ำเสมอ, OCR, สแกนช้ากว่า, มี parameter
Otsuหาอัตโนมัติ 1 ค่าhistogram 2 ยอดชัดเจนแสงไม่สม่ำเสมอ ยังพัง
เลือกยังไง?แสงดี → Global · แสงไม่เท่ากัน → Adaptive · ไม่รู้จะใช้ค่าอะไร + histogram 2 ยอด → Otsu

MORPHOLOGICAL PROCESSING

Morphology คืออะไร?

ปรับ "รูปร่าง" ของวัตถุในภาพ binary — ขยาย/หด/ลบจุดรบกวน ด้วย kernel (structuring element)

ใช้กับภาพอะไร?
Binary imageภาพขาว-ดำ (0/255) ที่ได้จาก threshold — morphology ทำงานบนภาพแบบนี้
Structuring elementkernel เล็ก ๆ (3×3) กำหนด "ย่านที่มอง" — เหมือน filter
เลื่อน+เปรียบเทียบดูว่าวัตถุชนกับ kernel หรือไม่ → ขยาย/หด
kernel = np.ones((3, 3), np.uint8)
res = cv2.morphologyEx(bin_img, cv2.MORPH_OPEN, kernel)

ได้อะไรจากการปรับรูปร่าง?

ลบจุด noise เล็ก ๆ · ปิดรู/รอยขาด · แยกวัตถุที่ติดกัน · ทำให้ contour สวยขึ้น

2 คำสั่งหลัก

Erosion หด · Dilation ขยาย — เอามาประกอบกันเป็น Opening/Closing (สไลด์ถัดไป)

เทคนิคสอบMorphology = ปรับรูปร่างภาพ binary · เครื่องมือ: erode (หด) / dilate (ขยาย)

EROSION

Erosion — กร่อน ขอบหด

ขอบของวัตถุถูก "กร่อน" ออก — จุดขาวเล็ก ๆ (noise) หายไป วัตถุบางลง

หลักการ
1วาง kernel บนพิกเซลขาวทุกจุด
2ถ้าทุกช่องใต้ kernel เป็นขาว → เก็บไว้
3ถ้ามีดำปน (ติดขอบ/จุดโดด) → ลบออก (กลายเป็นดำ)
eroded = cv2.erode(binary, kernel, iterations=1)
# kernel = np.ones((3,3), np.uint8)

ผลลัพธ์

วัตถุหดเล็กลงรอบด้าน · จุด noise ขนาดเล็ก (เล็กกว่า kernel) หายไปทั้งจุด

ระวัง

ทำหลายครั้ง (iterations) → วัตถุเล็กอาจหายทั้งชิ้น — ใช้พอประมาณ

เทคนิคสอบErosion = หดขอบ + ลบจุดขาว noise · cv2.erode(img, kernel)

DILATION

Dilation — ขยาย ขอบโต

ตรงข้ามกับ erosion — ขอบวัตถุขยายออก เอาไว้ปิดรู/รอยขาด หรือต่อวัตถุที่ขาด

หลักการ
1วาง kernel บนพิกเซลขาวทุกจุด
2ถ้ามีพิกเซลขาวอย่างน้อย 1 จุดใต้ kernel → จุดกลางกลายเป็นขาว
3ผล: ขอบขยายออกทุกทิศ
dilated = cv2.dilate(binary, kernel, iterations=1)

ใช้ทำอะไร

ปิดรูเล็ก ๆ ในวัตถุ · เชื่อมรอยขาดของเส้น · ทำให้ contour ไม่ขาดตอน

เทียบ Erosion

Erosion: ทุกช่องต้องขาว (AND) · Dilation: มีขาวแค่จุดเดียวพอ (OR) — จำจาก AND/OR

เทคนิคสอบDilation = ขยายขอบ + ปิดรู · cv2.dilate(img, kernel) · erode หด / dilate ขยาย

OPENING · CLOSING

Opening / Closing

เอา erode กับ dilate มาต่อกัน — ได้ผลลัพธ์ที่ใช้จริงในงาน

การดำเนินการลำดับผล
OpeningErosion → Dilationลบจุด noise ขาวเล็ก ๆ โดยไม่หดวัตถุใหญ่
ClosingDilation → Erosionปิดรู/รอยขาดในวัตถุ โดยไม่ขยายวัตถุใหญ่
จำยังไงไม่สลับ
Openingเริ่มด้วย Erosion (ลบจุดเล็กก่อน) → กลับมาขยาย → เหลือแต่วัตถุจริง
Closingเริ่มด้วย Dilation (ปิดรู) → กลับมาหด → วัตถุสมบูรณ์
opening = cv2.morphologyEx(b, cv2.MORPH_OPEN, k)
closing = cv2.morphologyEx(b, cv2.MORPH_CLOSE, k)

Opening ใช้ตอนไหน

ภาพ binary มีจุด noise กระจาย (จาก threshold) — ลบทิ้งก่อนนับวัตถุ

Closing ใช้ตอนไหน

วัตถุมีรู/รอยขาด (เช่น ตัวหนังสือขาดเส้น) — ปิดให้ต่อเนื่องก่อน contour

เทคนิคสอบOpening = erode→dilate (ลบจุดขาว) · Closing = dilate→erode (ปิดรูดำ) — เริ่มจากตัวแรกเป็นตัวหลัก

OBJECT DETECTION

Contour คืออะไร?

เส้นขอบที่ลากรอบวัตถุ (เส้นโค้งเชื่อมจุดขอบเดียวกัน) — ใช้บอกตำแหน่ง/รูปร่างของวัตถุ

จาก binary → contour

binary: วัตถุขาว

→

contour: เส้นรอบวัตถุ

Contourเส้นโค้งที่เชื่อมจุดขอบของวัตถุเดียวกัน
ใช้คำนวณArea (พื้นที่) · Perimeter (เส้นรอบรูป) · Shape (รูปร่าง)

Pipeline จริง

Threshold (แยกวัตถุ) → Morphology (ลบ noise) → findContours (หาวัตถุ) → นับ/วัด/ตรวจจับ

Contour vs Edge

Edge = จุดที่ความเข้มเปลี่ยน (พิกเซล) · Contour = เส้นปิดรอบวัตถุทั้งชิ้น (โครงสร้าง)

เทคนิคสอบContour = เส้นรอบวัตถุ · หาได้จากภาพ binary (ผ่าน threshold) · cv2.findContours()

OPENCV CODE

cv2.findContours() — หาวัตถุ

คำสั่งหาขอบวัตถุทั้งหมดในภาพ binary — คืนค่ารายการ contours

โค้ดมาตรฐาน 
# 1. เตรียมภาพ binary
ret, binary = cv2.threshold(
    gray, 128, 255, cv2.THRESH_BINARY)

# 2. หา contours
contours, hierarchy = cv2.findContours(
    binary, cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE)

# 3. วาดลงภาพ
cv2.drawContours(img, contours, -1,
                 (0, 255, 0), 2)

พารามิเตอร์

RETR_EXTERNAL = เอาเฉพาะขอบนอกสุด · CHAIN_APPROX_SIMPLE = เก็บเฉพาะมุม (ประหยัดหน่วยความจำ)

นับวัตถุ

print("พบวัตถุ", len(contours), "ชิ้น")
# แต่ละ contour = อาร์เรย์ของจุด (x, y)
เทคนิคสอบfindContours รับ binary · RETR_EXTERNAL = ขอบนอกสุด · CHAIN_APPROX_SIMPLE = เก็บมุม

BOUNDING BOX

Bounding Box — กล่องครอบวัตถุ

สี่เหลี่ยมที่เล็กที่สุดที่ครอบ contour ได้ — ใช้บอกตำแหน่งและขนาดของวัตถุ

โค้ด 
x, y, w, h = cv2.boundingRect(cnt)

# x, y = ตำแหน่งมุมซ้ายบน
# w    = ความกว้าง
# h    = ความสูง

cv2.rectangle(img, (x, y),
              (x + w, y + h),
              (0, 255, 0), 2)
1หาวัตถุด้วย contour
2ครอบด้วย bounding box (x, y, w, h)
3ใช้ตำแหน่งนั้นลากกรอบ/ตัดภาพ/ตรวจจับต่อ

เอาไปใช้ต่อ

ตัดภาพเฉพาะวัตถุ (crop) · วาดกรอบรอบชิ้นงาน · วัดขนาดจริงในหน่วย mm (เทียบสเกล)

วัดขนาด

จาก w, h (พิกเซล) + อัตราส่วนพิกเซลต่อมิลลิเมตร → คำนวณขนาดจริงของวัตถุได้

เทคนิคสอบboundingRect → (x, y, w, h) · สี่เหลี่ยมครอบ contour ที่เล็กสุด (axis-aligned)

FEATURE EXTRACTION

Feature Extraction — Shape · Moments

แปลง "รูปร่างของวัตถุ" ให้เป็นตัวเลข (features) ที่เครื่องคำนวณ/เปรียบเทียบได้

Feature จาก Contour
Shape FeaturesArea (พื้นที่) · Perimeter (เส้นรอบรูป) — วัดจาก contour
Momentsค่าทางคณิตศาสตร์ของรูปร่าง — บอกจุดศูนย์ถ่วง, พื้นที่, การกระจาย
ใช้แยกประเภทวงกลม vs สี่เหลี่ยม vs สามเหลี่ยม — ดูจากอัตราส่วนของ feature
area = cv2.contourArea(cnt)
peri = cv2.arcLength(cnt, True)
moments = cv2.moments(cnt)
cx = moments["m10"] / moments["m00"]  # centroid x
cy = moments["m01"] / moments["m00"]  # centroid y

แยกวงกลม vs สี่เหลี่ยม

วงกลม: area ≈ π·r² และ perimeter ≈ 2π·r · สี่เหลี่ยม: area = w·h — อัตราส่วน area/perimeter ต่างกัน

ทำไมต้องเป็นตัวเลข?

เครื่องเปรียบเทียบตัวเลขได้ — feature เหล่านี้คือ input ของ ML/การจำแนก (บทท้าย)

เทคนิคสอบFeature = ตัวเลขจากรูปร่าง · contourArea = พื้นที่ · arcLength = เส้นรอบรูป · moments = จุดศูนย์ถ่วง

CORNER DETECTION

Corner Detection — Harris / Shi-Tomasi

หาจุด "มุม" ของภาพ — จุดที่มองจากทิศไหนก็เห็นการเปลี่ยนแปลง (โดดเด่น ไม่ซ้ำ)

ทำไมมุมถึงพิเศษ?
มุม (Corner)เลื่อนนิดเดียว ค่าพิกเซลเปลี่ยนทุกทิศ → จดจำง่าย ไม่กำกวม
ขอบ (Edge)เปลี่ยนแค่ทิศเดียว — เลื่อนตามขอบแล้วเหมือนเดิม
พื้นที่เรียบเลื่อนยังไงก็เหมือนเดิม — ไม่มีข้อมูล
# Harris
corners = cv2.cornerHarris(gray, 2, 3, 0.04)
# Shi-Tomasi (ดีที่สุด N จุด)
pts = cv2.goodFeaturesToTrack(gray, 50, 0.01, 10)

ใช้กับงานไหน

ติดตามวัตถุ (tracking) · จับคู่ภาพ (matching) · หาจุดอ้างอิงในภาพ

Harris vs Shi-Tomasi

Harris ให้คะแนนมุมทุกจุด · Shi-Tomasi (goodFeaturesToTrack) คืนเฉพาะ N จุดที่ดีที่สุด

เทคนิคสอบCorner = จุดที่เปลี่ยนทุกทิศ · Harris (cornerHarris) / Shi-Tomasi (goodFeaturesToTrack)

FEATURE DESCRIPTOR

Feature Descriptor — SIFT / SURF / ORB

เลขชุดหนึ่งที่อธิบาย "หน้าตา" รอบจุดเด่น — ใช้อ่านตรงไหนในภาพ 2 ใบว่าเหมือนกัน

Descriptor คืออะไร
1หาจุดเด่น (keypoint) — มุม/จุดที่น่าสนใจ
2บันทึกรูปแบบรอบจุดนั้นเป็น "เลขบรรยาย" (vector)
3ภาพอื่นเจอเลขใกล้เคียงกัน → เจอจุดเดียวกัน
orb = cv2.ORB_create()
kp, des = orb.detectAndCompute(gray, None)
# des = descriptor ของแต่ละ keypoint

3 ตัวหลัก

SIFT = แม่นยำสูง (แต่ช้า, จดสิทธิบัตร) · SURF = SIFT เวอร์ชันเร็ว · ORB = ฟรี เร็ว เหมาะมือถือ/เรียลไทม์

ใช้กับงาน

จับคู่ภาพ (image matching) · สร้าง panorama (stitching) · หาวัตถุในภาพ 2 ใบ

เทคนิคสอบSIFT (แม่น/ช้า) · SURF (เร็ว) · ORB (ฟรี+เร็ว) · ใช้ detectAndCompute → kp, des

IMAGE TRANSFORMATION

Geometric Transform — Resize · Rotate · Translate

เปลี่ยนตำแหน่ง/ขนาด/ทิศของภาพ — ย่อ-ขยาย หมุน เลื่อน ด้วยเมทริกซ์แปลง

3 คำสั่งหลัก 
# Resize — ย่อ/ขยาย
resized = cv2.resize(img, (640, 480))

# Rotate — หมุน (90° ทวีคูณ)
rotated = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)

# Translate — เลื่อน (เมทริกซ์)
M = np.float32([[1, 0, 50], [0, 1, 30]])
shifted = cv2.warpAffine(img, M, (w, h))
warpAffineแปลงแบบเลื่อน/หมุน/ย่อ (affine — เส้นขนานยังขนาน)
warpPerspectiveแปลงมุมมอง 4 จุด (ไปดูสไลด์ถัดไป)

ใช้กับงาน

ปรับขนาดภาพก่อนเข้าโมเดล (resize) · จัดแนวภาพก่อน compare · เลื่อนกรอบ ROI

Resize สำคัญกับ AI

โมเดล CNN รับขนาดคงที่ (เช่น 224×224) — ต้อง resize ทุกภาพให้ขนาดเดียวกันก่อน

เทคนิคสอบresize = ย่อ/ขยาย · rotate = หมุน · warpAffine = เลื่อน/หมุน/ย่อ (affine)

PERSPECTIVE TRANSFORM

Perspective Transform — สแกนเอกสาร

แก้ภาพที่ถ่ายเอียง/เบี้ยวให้ตรง — เอา 4 มุมของเอกสารมายืดให้เป็นสี่เหลี่ยม

ขั้นตอน
1หาตำแหน่ง 4 มุมของเอกสารในภาพ (เช่น ใช้ contour)
2กำหนดจุดปลายทาง (สี่เหลี่ยมตรง ๆ)
3คำนวณเมทริกซ์ + warp → ได้ภาพตรง เหมือนสแกน
pts_src = np.float32([
    [x1, y1], [x2, y2], [x3, y3], [x4, y4]])
pts_dst = np.float32([
    [0, 0], [w, 0], [w, h], [0, h]])
M = cv2.getPerspectiveTransform(pts_src, pts_dst)
scanned = cv2.warpPerspective(img, M, (w, h))

ตัวอย่างการใช้งาน

แอพสแกนเอกสาร (CamScanner) · ถ่ายป้าย/บอร์ดเอียง ๆ ให้ตรงก่อน OCR · ถ่ายเมนู

Affine vs Perspective

Affine = เลื่อน/หมุน/ย่อ (เส้นขนานคงขนาน) · Perspective = เปลี่ยนมุมมอง 4 จุด (เส้นอาจไม่ขนาน)

เทคนิคสอบPerspective = แก้เอียงด้วย 4 มุม · getPerspectiveTransform + warpPerspective

ADVANCED IMAGE PROCESSING

Advanced — Restoration · Stitching

งานขั้นสูงที่ต่อยอดจากทุกบทที่เรียนมา — ฟื้นฟูภาพ และต่อภาพพาโนรามา

Image Restoration
Deblurแก้ภาพเบลอ (จากมือสั่น/โฟกัสพลาด) — ใช้ความรู้เรื่อง kernel/convolve
Denoisingลบ noise — ต่อยอดจากบท 5 (median/gaussian/bilateral)
Frequency domainใช้ Fourier (บท 5) กรอง/ซ่อมภาพแบบความถี่

Image Stitching

ต่อภาพถ่ายหลายใบเป็นภาพพาโนรามา — ใช้ feature matching (SIFT/ORB จากสไลด์ 21) หาจุดที่ตรงกันแล้วต่อ

เชื่อมกับบทก่อนหน้า

Restoration ใช้ filter (บท 5) + Fourier · Stitching ใช้ feature (บทนี้) + perspective (สไลด์ 23)

เทคนิคสอบRestoration = deblur + denoising · Stitching = ต่อภาพ panorama ด้วย feature matching

COMPUTER VISION + AI

Computer Vision + AI — ML · DL · CNN

จากกฎที่เขียนด้วยมือ (threshold/contour) ไปถึงระบบที่ "เรียนรู้" เองจากข้อมูล

วิวัฒนาการ
Classic CVกฎเขียนด้วยมือ: threshold + contour + feature (ที่เรียนมา)
Machine LearningFeature extraction (ด้วยมือ) → Classification (SVM, Random Forest)
Deep LearningCNN เรียนรู้ feature เองจากภาพตรง ๆ — ไม่ต้องออกแบบ feature

CNN คืออะไร

Convolutional Neural Network — โครงข่ายที่ใช้ convolution (kernel!) หลายชั้น เรียนรู้ค่าถ่วงน้ำหนักเองจากข้อมูล

Framework

PyTorch · TensorFlow · Model Zoo (โมเดลสำเร็จ) · Transfer Learning (เอาความรู้เดิมมาต่อยอด)

เทคนิคสอบML = feature ด้วยมือ + classifier · DL/CNN = เรียนรู้ feature เอง · Framework: PyTorch/TensorFlow

OBJECT DETECTION MODELS

Object Detection — YOLO · SSD · Faster R-CNN

โมเดลที่บอกทั้ง "อะไร" (class) และ "อยู่ตรงไหน" (bounding box) ในภาพเดียว

โมเดลแนวคิดจุดเด่น
YOLOดูทั้งภาพครั้งเดียว (one-stage) — เร็วมากเรียลไทม์ (วิดีโอ/กล้อง)
SSDSingle Shot — ตรวจจับหลายขนาดในครั้งเดียวเร็ว + แม่นยำสมดุล
Faster R-CNNสองขั้นตอน: เสนอพื้นที่ → จำแนก (two-stage)แม่นยำสูงสุด แต่ช้า
Output ของ object detection
Bounding box(x, y, w, h) — ตำแหน่งวัตถุ (เหมือน boundingRect ที่เรียนมา)
Class + Confidenceเช่น "person 0.95" — เป็นคน 95%
เทคนิคสอบYOLO = เร็ว (หนึ่งรอบ) · Faster R-CNN = แม่น (สองขั้นตอน) · SSD = กลาง ๆ — จำความสัมพันธ์เร็ว↔แม่น
