1 · OpenCV คืออะไร & ภาพ = NumPy Array

  • OpenCV = Open Source Computer Vision Library — ไลบรารี (ชุดคำสั่งสำเร็จรูป) สำหรับอ่าน/แก้ไข/วิเคราะห์ภาพและวิดีโอ · ใช้ทำ face/object detection, OCR, นับสิ่งของ, AR
  • เริ่มจาก Intel ปี 1999 (Gary Bradski) → ตอนนี้ดูแลโดยทีม OpenCV.org · ฟรี Open Source ใช้ได้ทั้งงานวิจัยและเชิงพาณิชย์
  • รองรับ C++ / Python / Java / JavaScript — บทนี้ใช้ Python · มีอัลกอริทึมสำเร็จรูป กว่า 2,500 ตัว
  • ติดตั้ง: pip install opencv-python numpy matplotlib → เริ่มทุกไฟล์ด้วย import cv2
  • ภาพ = NumPy array (ตารางตัวเลข) — แต่ละช่อง = ค่าพิกเซล (ยิ่งเลขมากยิ่งสว่าง) · แก้พิกเซล = แก้ตัวเลขในตาราง
  • ภาพสี = array 3 มิติ (แถว, คอลัมน์, ช่องสี) — แต่ละจุดมีค่า 3 ตัว (B, G, R)
  • ทำไมต้อง NumPy: คำนวณทั้ง array ได้เร็ว (vectorized) — เช่น ปรับความสว่างทั้งภาพ = บวกเลขทั้งตารางครั้งเดียว · type(img) → numpy.ndarray

2 · อ่าน · แสดง · บันทึกภาพ

  • อ่าน: img = cv2.imread("image.jpg") → ได้ NumPy array · path ผิดจะได้ None — ควรเช็คเสมอ · cv2.imread(path, 0) = อ่านเป็น grayscale 1 ช่อง
  • ตอนอ่าน นามสกุลไม่สำคัญ (OpenCV เดารูปแบบจากเนื้อไฟล์) แต่ตอนบันทึก นามสกุลกำหนดรูปแบบไฟล์ (jpg/png/bmp)
  • แสดงแบบ OpenCV — ต้อง 3 คำสั่งคู่กัน:
    cv2.imshow("Image", img) # 1. เปิดหน้าต่าง cv2.waitKey(0) # 2. รอคีย์บอร์ด cv2.destroyAllWindows() # 3. ปิดหน้าต่างทั้งหมด
  • ⚠ ลืม waitKey = หน้าต่างกะพริบแล้วปิดทันที · waitKey(0) = รอไม่จำกัด · waitKey(5000) = รอ 5 วิ (หน่วยมิลลิวินาที)
  • แสดงแบบ Matplotlib (นิยมใน Jupyter/Colab): plt.imshow(img, cmap="gray") + plt.show() — ภาพสีต้อง cvtColor BGR→RGB ก่อน! · cmap ที่มี: gray · hot · viridis · jet · plasma
  • บันทึก: cv2.imwrite("roi.jpg", roi) — อาร์กิวเมนต์แรก = path ไฟล์ใหม่, ตัวที่สอง = ภาพ · คืน True/False ว่าสำเร็จไหม
  • จัดหน้าต่าง Matplotlib: plt.subplot(แถว, คอลัมน์, ตำแหน่ง) เช่น subplot(1,2,1) = 1 แถว 2 คอลัมน์ ช่องซ้าย · plt.title() · plt.xlabel()/ylabel() · plt.colorbar()
  • พล็อตเสริม: plt.hist(img.ravel(), bins=256) (histogram ค่าพิกเซล) · plt.plot(100, 200, "ro") จุดแดง · plt.text(100,100,"Pixel") · plt.xlim/ylim (ใส่ ylim(300,100) = กลับแกน) · plt.grid() · plt.axis("off")

3 · img.shape & img.dtype

  • img.shape = (Height, Width, Channels) — ภาพ 640×480 สี → (480, 640, 3)
  • ⚠ กับดักที่เจอบ่อยที่สุด: Height (แถว/y) มาก่อน Width (คอลัมน์/x) เสมอ — เพราะ array เรียงแถวก่อนคอลัมน์
  • แยกอ่าน: h, w = img.shape[:2] (grayscale ไม่มีช่อง) · h, w, c = img.shape (ภาพสี)
  • img.dtype = uint8 — unsigned 8-bit integer = 0–255 (u = ไม่มีค่าลบ เริ่ม 0 · 8 บิต = 2⁸−1 = 255)
  • ⚠ เวลาคำนวณ: uint8 เก็บ 0–255 เท่านั้น — คำนวณเกิน 255 จะ wrap (วนกลับ)/clip → ต้องแปลงเป็น float ก่อนแล้วค่อยกลับ (float32/64 ใช้ตอนคำนวณ · uint16 สำหรับภาพ 16 บิต)

4 · BGR vs RGB — กับดักสีสลับ

  • OpenCV เก็บช่องสีเรียง BGR (Blue-Green-Red) — มรดกจากยุคแรกของ C/C++ · แต่ Matplotlib/ภาพทั่วไปเรียง RGB — สอบติดชัวร์!
  • ตัวอย่าง: pixel = [50, 120, 200] — อ่านแบบ OpenCV (BGR) = B 50 · G 120 · R 200 (โทนแดง) / แบบ RGB = R 50 · B 200 (โทนน้ำเงิน) → แดงกับน้ำเงินสลับกัน ภาพเพี้ยน (อาการคลาสสิก: ท้องฟ้ากลายเป็นส้ม)
  • แก้: img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB) แล้วค่อย plt.imshow
  • อ่านชื่อ flag: COLOR_A2B = แปลงจาก A → B · flag อื่น: COLOR_BGR2GRAY · COLOR_RGB2BGR · COLOR_BGR2HSV · COLOR_BGR2LAB
  • สลับด้วย slicing ก็ได้: img_rgb = img[:, :, ::-1] (กลับลำดับช่องสุดท้าย — เทียบเท่า cvtColor สำหรับ BGR↔RGB)

5 · จัดการพิกเซล — img[y, x]

  • กฎเหล็ก: img[แถว(y), คอลัมน์(x)] — y มาก่อน x เสมอ (ต่างจากคณิตศาสตร์ที่ใช้ (x, y) → เขียน img[x, y] จะได้ตำแหน่งคนละจุด!)
  • อ่าน: pixel = img[100, 200] → ภาพสีได้ [B, G, R] 3 ตัว · ภาพเทาได้ค่าเดียว เช่น img[100, 200] = 120
  • แยกช่อง: b, g, r = img[100, 200] หรือระบุดัชนี img[100, 200, 0]=B · [..., 1]=G · [..., 2]=R · ดึงช่องทั้งภาพ: blue = img[:, :, 0] (ไว้ทำ mask/แยกวัตถุด้วยสี)
  • ตั้งค่า: img[100, 200] = [0, 0, 255] — สีแดงใน BGR! (แดง RGB = [255,0,0] แต่ OpenCV สลับเป็น [0,0,255])
  • สีที่ใช้บ่อย (BGR): แดง [0,0,255] · เขียว [0,255,0] · น้ำเงิน [255,0,0] · ขาว [255,255,255] · ดำ [0,0,0]
  • เปลี่ยนทั้งโซน: img[100:200, 100:300] = [0, 0, 255] — slicing เติมทั้งบล็อกในครั้งเดียว (ปิดบังใบหน้า/ทะเบียน, watermark, mask)
  • ⚠ ช่วงสุดท้ายไม่รวม: 100:200 ครอบแถว 100–199 — เหมือน Python slicing ทั่วไป

6 · ROI — Region Of Interest

  • ROI = Region Of Interest = บริเวณที่เราสนใจในภาพ — ตัดเฉพาะส่วนนั้นมาแล้วประมวลผลต่อ
  • ทำไมต้อง ROI: 1. เร็วขึ้น (คำนวณน้อยลง) 2. แม่นขึ้น (ไม่โดนพื้นหลัง/noise รบกวน) 3. วิเคราะห์เฉพาะจุดง่าย
  • ตัด: roi = img[y1:y2, x1:x2] เช่น roi = img[100:300, 200:500] → y = 100–300, x = 200–500, ได้ roi.shape = (200, 300, 3) (สูง 200 แถว, กว้าง 300 คอลัมน์)
  • ⚠ slicing เป็น view: แก้ roi แล้วภาพต้นฉบับเปลี่ยนตาม — อยากได้สำเนาใช้ roi = img[y1:y2, x1:x2].copy()
  • งานจริง (detect → ตัด ROI → วิเคราะห์): OCR อ่านตัวหนังสือ · ป้ายทะเบียนรถ · ตรวจจับใบหน้า
  • ROI ลดงาน: ทั้งภาพ 1920×1080 = 2,073,600 px แต่ ROI 300×300 = 90,000 px → 90,000 ÷ 2,073,600 ≈ 4.3% (ประมวลผล ~23 เท่าเร็วขึ้น เพราะงานคิดต่อพิกเซล)
  • โจทย์สอบ: % ที่ประมวลผล = พิกเซล ROI ÷ พิกเซลทั้งหมด × 100

7 · โค้ดรวมทั้งบท (อ่าน → ROI → แสดง → บันทึก)

import cv2 img = cv2.imread("image.jpg") # 1. อ่านภาพ → array print(img.shape) # (480, 640, 3) = (H, W, C) roi = img[100:300, 200:500] # 2. ตัด ROI (y ก่อน x เสมอ) cv2.imshow("Original", img) # 3. แสดงภาพเดิม + ROI cv2.imshow("ROI", roi) cv2.waitKey(0) # 4. รอคีย์บอร์ด (ลืม = หน้าต่างปิดทันที) cv2.destroyAllWindows() # 5. ปิดหน้าต่าง cv2.imwrite("roi.jpg", roi) # 6. บันทึก (นามสกุลกำหนดรูปแบบ)

ขั้นตอนระบบจริง: หาของ (detect) → ตัด ROI → วิเคราะห์เฉพาะ ROI — ลดทั้งงานคำนวณและ noise

8 · ตารางคำสั่งหลักที่ต้องรู้จัก

คำสั่งหน้าที่ตัวอย่าง

9 · คำศัพท์ที่ต้องรู้ (Glossary ฉบับย่อ)

  • OpenCV — Open Source Computer Vision Library · ไลบรารีประมวลผลภาพ/CV ยอดนิยม
  • NumPy Array — โครงสร้างที่ OpenCV ใช้เก็บภาพ (H, W, C)
  • uint8 — unsigned 8-bit integer · เก็บค่าพิกเซล 0–255
  • BGR — ลำดับช่องสีของ OpenCV: Blue, Green, Red (สลับจาก RGB)
  • Channel — ช่องสี · ดัชนี 0=B, 1=G, 2=R
  • Pixel Access — img[y, x] · y = แถว (row) · x = คอลัมน์ (column)
  • ROI — Region Of Interest · บริเวณที่สนใจ ตัดด้วย img[y1:y2, x1:x2]
  • Slicing — การตัด array ด้วยเครื่องหมาย : เช่น img[100:300, 200:500]
  • View — slicing ได้มุมมองชี้ไปที่ข้อมูลเดิม (แก้แล้วกระทบต้นฉบับ) ต่างจาก .copy()
  • Matplotlib — ไลบรารีพล็อตของ Python · plt.imshow() แสดงภาพ
  • cmap — color map เปลี่ยนโทนสีภาพเทา: gray · hot · viridis · jet · plasma
  • ravel() — แผ่ array หลายมิติเป็นเส้นตรง · ใช้คู่ plt.hist

10 · กับดักที่ข้อสอบชอบหลอก

  • ⚠ img.shape = (H, W, C) — 480 (แถว) มาก่อน 640 (คอลัมน์) เสมอ
  • ⚠ เข้าถึงพิกเซล img[y, x] — ไม่ใช่ img[x, y]
  • ⚠ แดงใน OpenCV = [0, 0, 255] (BGR) — ไม่ใช่ [255, 0, 0]
  • ⚠ ดัชนีช่อง: 0 = B · 1 = G · 2 = R
  • ⚠ imshow ต้องคู่กับ waitKey(0) — ลืม = หน้าต่างปิดทันที
  • ⚠ ภาพสีโชว์ด้วย Matplotlib ต้อง cvtColor BGR→RGB ก่อน ไม่งั้นสีเพี้ยน
  • ⚠ slicing ช่วงสุดท้ายไม่รวม: 100:200 = แถว 100–199
  • ⚠ roi = slicing เป็น view — แก้ roi กระทบต้นฉบับ ต้อง .copy()
  • ⚠ imread path ผิด → คืน None (ไม่ error) — ควรเช็ค
  • ⚠ uint8 คำนวณเกิน 255 → wrap/clip — แปลง float ก่อนคำนวณ
  • ⚠ imread ≠ imshow — อ่าน vs แสดง อย่าสลับ

11 · คำถาม-คำตอบฉบับเร็ว (จากแบบทดสอบบทนี้)

  • คำสั่งอ่านภาพ? → cv2.imread("image.jpg")
  • shape ของภาพ 640×480 สี? → (480, 640, 3) — H ก่อน W
  • shape ของภาพ 720×1280 สี? → (720, 1280, 3)
  • dtype ของภาพปกติ? → uint8 (0–255)
  • imshow ต้องคู่กับ? → cv2.waitKey()
  • waitKey(0) หมายถึง? → รอจนกว่าจะกดปุ่มใดก็ได้ (5000 = รอ 5 วิ)
  • OpenCV เรียงช่องสีแบบใด? → BGR (Blue-Green-Red)
  • แปลง BGR→RGB? → cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
  • พิกเซลแถว 100 คอลัมน์ 200? → img[100, 200]
  • b, g, r = img[y,x] — b คือ? → Blue (ช่อง 0)
  • เอาช่องน้ำเงินของ (100, 200)? → img[100, 200, 0]
  • เปลี่ยนพิกเซล (100, 200) เป็นแดง? → img[100, 200] = [0, 0, 255]
  • ROI ย่อมาจาก? → Region Of Interest
  • ตัด ROI แถว 100–300 คอลัมน์ 200–500? → img[100:300, 200:500]
  • บันทึกภาพลงไฟล์? → cv2.imwrite("roi.jpg", roi)
  • destroyAllWindows() ใช้ทำอะไร? → ปิดหน้าต่างทั้งหมดที่ imshow สร้าง
  • ภาพที่ imread คืนมาเป็น? → NumPy Array
  • plt.hist(img.ravel(), bins=256)? → วาด histogram ของค่าพิกเซล
  • ทำไมต้องแปลง BGR→RGB ก่อน plt.imshow? → OpenCV เก็บ BGR แต่ Matplotlib แสดง RGB — ไม่แปลง = สีสลับ/เพี้ยน
  • ROI 300×300 จากภาพ 1920×1080 คิดเป็นกี่ %? → 90,000 ÷ 2,073,600 ≈ 4.3%
