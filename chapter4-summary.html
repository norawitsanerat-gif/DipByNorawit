1 · Image Enhancement คืออะไร

  • Image Enhancement = ทำให้ภาพดูดีขึ้น ก่อนเอาไปวิเคราะห์ต่อ — ปรับความสว่าง, คอนทราสต์, ลด noise
  • เครื่องมือหลัก: Brightness (beta) · Contrast (alpha) · Gamma / Log (ปรับโทนแบบไม่เชิงเส้น) · Histogram (วิเคราะห์การกระจาย) · Equalization (กระจาย histogram) · CLAHE (equalize แบบ local)
  • Pipeline งานจริง: Camera → Image Enhancement (บทนี้!) → Threshold (แยก object/background) → Contour (หาขอบเขต) → Object Detection (ตรวจจับ/นับวัตถุ)

2 · Brightness & Contrast — convertScaleAbs

  • Brightness (ความสว่าง) = beta — บวก/ลบค่าคงที่กับทุกพิกเซลเท่า ๆ กันทั้งภาพ · cv2.convertScaleAbs(img, beta=50) = สว่างขึ้น 50 · beta=−50 = มืดลง (beta เป็นลบได้)
  • Contrast (คอนทราสต์) = alpha — คูณค่าคงที่ทุกพิกเซล · alpha > 1 = ระยะห่างค่ากว้างขึ้น → contrast เพิ่ม · alpha < 1 = ค่ารวมเข้าหากัน → contrast ลด (ซีด)
  • สูตรรวม: new = (alpha × pixel) + beta — คูณ alpha (contrast) ก่อน → บวก beta (brightness) → คลิป 0–255 (เกิน 255 → 255, ต่ำกว่า 0 → 0)
  • ตัวอย่าง: pixel = 100, alpha = 1.5, beta = 30 → (1.5×100)+30 = 180 · pixel = 200 → (1.5×200)+30 = 330 → คลิปเป็น 255
  • cv2.convertScaleAbs(img, alpha=1.5, beta=30) — ทำทั้งหมดในตัว: Scale (คูณ+บวก) · Abs (ค่าสัมบูรณ์กันค่าลบ) · คลิป 0–255 + แปลง uint8 อัตโนมัติ
  • เขียนเองก็เหมือนกัน: new = np.clip(img.astype(float)*1.5 + 30, 0, 255).astype("uint8")

3 · Contrast Stretching — ยืดช่วงค่า

  • ภาพซีด = ค่าพิกเซลอยู่ในช่วงแคบ (เช่น 50–150) → ยืดให้เต็ม 0–255 เห็นความต่างชัดขึ้น
  • หลักการ: หาค่าต่ำสุด-สูงสุดของภาพ → map ใหม่ (ต่ำสุด → 0, สูงสุด → 255, ค่ากลางยืดตามสัดส่วน)
  • ใช้เมื่อ: ภาพคอนทราสต์ต่ำ (ทุกค่าอยู่กลาง ๆ) เช่น ภาพที่แสงแย่ถ่ายกลางแจ้ง

4 · Gamma Transformation — s = c·r^γ

  • Power-Law Transform: s = c·r^γ — r = ค่าอินพุต (normalize 0–1 ก่อน แล้วคูณกลับ 255) · s = เอาต์พุต · c = ค่าคงที่ (ปกติ 1) · γ = ตัวยกกำลัง
  • จำ 3 กรณี: γ < 1 → ภาพสว่างขึ้น (ดันค่ามืดขึ้น เห็นเงา) เช่น γ = 0.5 แก้ภาพมืด/ย้อนแสง · γ = 1 → ไม่เปลี่ยน (r¹ = r) · γ > 1 → ภาพมืดลง (กดค่าสว่างลง) เช่น γ = 2.2
  • γ = 2.2 = มาตรฐาน sRGB ของจอ — ใช้ตอนแสดงผล / ลดความสว่างภาพที่สว่างเกิน · แก้ภาพมืดใช้ γ = 0.5
  • ตัวอย่าง: 0.25^0.5 = 0.5 (มืดขึ้นสว่าง) · 0.75^2.2 ≈ 0.53 (สว่างลงมืด)

5 · Logarithmic Transformation — s = c·log(1+r)

  • s = c·log(1+r) — log ยกค่ามืดขึ้นมาก แต่ค่าสว่างแทบไม่เปลี่ยน → เน้นรายละเอียดในเงามืด (เช่น r=5 → log(6)≈1.79 เพิ่ม ~2.6 เท่า, r=250 → log(251)≈5.52 เพิ่ม ~1.02 เท่า)
  • เหมาะกับภาพ dynamic range กว้าง (สว่างจ้า + มืดสนิทในภาพเดียว เช่น ถ่ายย้อนแสง)
  • +1 ใน log(1+r) กัน log(0) = −∞ (ค่าต่ำสุด = log(1) = 0)
  • เทียบกับ Gamma: ทั้งคู่ช่วยเงามืด — Gamma ปรับละเอียดกว่าด้วยค่า γ ตัวเดียว · Log ตายตัว

6 · Histogram — กราฟการกระจายพิกเซล

  • Histogram = กราฟนับจำนวนพิกเซลต่อระดับความเข้ม (0–255) — แกน x = ค่าพิกเซล, แกน y = จำนวนพิกเซล (แท่งสูง = มีพิกเซลเยอะที่ค่านั้น)
  • คำนวณ: cv2.calcHist([gray], [0], None, [256], [0, 256]) หรือ plt.hist(img.ravel(), bins=256)
  • อ่าน 3 รูปแบบ: แท่งเบียดซ้าย = ภาพมืด (Underexposed) · แท่งเบียดขวา = ภาพสว่างเกิน (Overexposed) · แท่งรวมกลางแคบ ๆ = คอนทราสต์ต่ำ (ซีด) · กระจายเต็ม 0–255 = ภาพดี
  • ดู histogram ก่อนปรับภาพเสมอ — บอกภาพมืด/สว่าง/contrast ต่ำ-สูง

7 · Histogram Equalization

  • กระจาย histogram ที่เบียดกันให้ "แบน" ครอบทั้ง 0–255 → คอนทราสต์ดีขึ้นอัตโนมัติ (ใช้ cumulative/สะสมของ histogram สร้างตารางแปลงค่า)
  • โค้ด: eq = cv2.equalizeHist(gray) — ใช้ได้กับภาพ 1 ช่อง (grayscale) เท่านั้น!
  • ภาพสี: แปลงเป็น YUV → equalize ช่อง Y (ความสว่าง) → แปลงกลับ — ทำที่ RGB ตรง ๆ จะสีเพี้ยน (cvtColor(COLOR_BGR2YUV) → yuv[:,:,0] = equalizeHist(...) → COLOR_YUV2BGR)
  • ข้อระวัง: ภาพ noise เยอะ → equalize ทั้งภาพอาจทำให้ noise โผล่ชัดขึ้น (แก้ด้วย CLAHE)

8 · CLAHE — Equalization แบบ Local

  • CLAHE = Contrast Limited Adaptive Histogram Equalization — แบ่งภาพเป็นบล็อกเล็ก (tile) แล้ว equalize ทีละบล็อกด้วย histogram ของตัวเอง + จำกัด contrast (clipLimit)
  • โค้ด: clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8)) → res = clahe.apply(gray)
  • ดีกว่า equalize ปกติ: ไม่ทำให้ noise โผล่ทั้งภาพ (จำกัด contrast ต่อบล็อก) · ปรับตามแสงเฉพาะที่ → เหมาะภาพแสงไม่สม่ำเสมอ/มี noise

9 · สูตร & เลขต้องจำก่อนเข้าห้องสอบ

  • Brightness = beta (บวก/ลบ) · Contrast = alpha (คูณ) — อย่าสลับ
  • new = (alpha × pixel) + beta → คลิป 0–255 · alpha>1 เพิ่ม contrast · alpha<1 ลด
  • s = c·r^γ — γ<1 สว่าง · γ=1 เดิม · γ>1 มืด · γ จอ = 2.2 · แก้ภาพมืด = 0.5
  • s = c·log(1+r) — เน้นรายละเอียดในเงามืด · dynamic range กว้าง
  • Contrast Stretching = ยืดช่วงแคบ (50–150) → 0–255
  • Histogram: ซ้าย = มืด · ขวา = สว่าง · กลางแคบ = ซีด · กระจายทั่ว = ดี
  • equalizeHist = grayscale 1 ช่อง · ภาพสี → YUV ช่อง Y · CLAHE = createCLAHE + apply

10 · กับดักที่ข้อสอบชอบหลอก

  • ⚠ beta = บวก/ลบ (brightness) · alpha = คูณ (contrast) — อย่าสลับกัน
  • ⚠ สูตรรวม: คูณ alpha ก่อน แล้วค่อยบวก beta
  • ⚠ คลิป 0–255: 200×1.8 = 360 → 255 (ไม่ใช่ 360)
  • ⚠ γ<1 = สว่าง, γ>1 = มืด — อย่าจำกลับ (γ=2.2 ไม่ใช่ทำให้สว่าง)
  • ⚠ equalizeHist รับได้แค่ 1 ช่อง — ภาพสีต้องแปลง YUV ไม่ใช่ทำ RGB ตรง ๆ
  • ⚠ histogram เบียดซ้าย = ภาพมืด (ค่าต่ำ) · เบียดขวา = สว่างเกิน — อย่าสลับ
  • ⚠ CLAHE = local (บล็อกเล็ก) ไม่ใช่ global
  • ⚠ log ต้อง +1 ใน log(1+r) — กัน log(0) = −∞
  • ⚠ Contrast Stretching = ยืดช่วงให้กว้าง — ไม่ใช่บีบให้แคบ

11 · คำถาม-คำตอบฉบับเร็ว (จากแบบทดสอบบทนี้)

  • เพิ่มความสว่างใช้พารามิเตอร์ใด? → beta (บวกค่าคงที่ทุกพิกเซล)
  • เพิ่มคอนทราสต์ใช้พารามิเตอร์ใด? → alpha (คูณค่าคงที่)
  • สูตรรวม Brightness + Contrast? → new = (alpha × pixel) + beta
  • convertScaleAbs(img, beta=50) มีผล? → ภาพสว่างขึ้น 50 ระดับ (beta=−50 = มืดลง)
  • convertScaleAbs(img, alpha=1.8)? → คอนทราสต์เพิ่มขึ้น (alpha>1)
  • alpha = 0.5? → คอนทราสต์ลดลง (ค่าถูกรวมเข้าหากัน)
  • convertScaleAbs คลิปค่าเท่าไร? → 0–255 (uint8)
  • pixel = 200, alpha = 1.8 ได้ค่า? → 200×1.8 = 360 → คลิป = 255
  • สูตร Gamma? → s = c·r^γ (Power-Law)
  • γ < 1 (เช่น 0.5) มีผล? → ภาพสว่างขึ้น เห็นเงามืดชัดขึ้น
  • gamma มาตรฐานจอ? → 2.2 (sRGB) · แก้ภาพมืดใช้ 0.5
  • Histogram คืออะไร? → การกระจายของจำนวนพิกเซลต่อระดับความเข้ม 0–255
  • ภาพมืดเกิน histogram แบบใด? → แท่งส่วนใหญ่อยู่ทางซ้าย (ค่าต่ำ) · ภาพสว่าง = เบียดขวา
  • ภาพคอนทราสต์ต่ำ histogram? → แท่งรวมกลางแคบ ๆ
  • Histogram Equalization ทำอะไร? → กระจาย histogram ให้ทั่วทั้งช่วง 0–255
  • equalizeHist ใช้กับภาพแบบใด? → Grayscale (1 ช่อง) — ภาพสีทำที่ช่อง Y (YUV)
  • CLAHE ต่างจาก equalize ยังไง? → ปรับเป็นบล็อกเล็ก ๆ (local) แทนทั้งภาพ + จำกัด contrast
  • Contrast Stretching คือ? → ยืดช่วงค่าที่แคบ (50–150) ให้กว้าง (0–255)
  • Log transform เหมาะกับภาพแบบใด? → dynamic range กว้าง / เน้นรายละเอียดในเงามืด
  • Pipeline งานจริง? → Camera → Enhancement → Threshold → Contour → Object Detection
