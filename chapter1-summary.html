1 · ภาพดิจิทัล = f(x, y) — กับพิกเซล (Pixel)

  • ภาพ = ฟังก์ชัน 2 มิติ f(x, y) — x, y = ตำแหน่ง (x แนวนอน, y แนวตั้ง), ค่าของ f = ความเข้ม/ระดับเทา (intensity / gray level) ณ จุดนั้น
  • จะเรียกว่า “ดิจิทัล” เมื่อทั้ง ตำแหน่ง (x,y) และ ความเข้ม ถูกแบ่งเป็นค่า จำกัด/ไม่ต่อเนื่อง (discrete / finite)
  • ภาพ = องค์ประกอบจำนวนจำกัด แต่ละตัวมี ตำแหน่ง (location) + ค่า (value) → เรียกว่า พิกเซล (Pixel = Pic-ture El-ement) = จุดเล็กที่สุดของภาพ
  • 1 พิกเซล เก็บ 2 อย่าง: (1) ตำแหน่ง (x,y) (2) ค่า — ระดับเทา หรือสี RGB/BGR
  • พิกเซลเยอะขึ้น → ละเอียด (detail) มากขึ้น แต่ไฟล์ใหญ่ขึ้น + ประมวลผลช้าลง
  • OpenCV เข้าถึงพิกเซลด้วย img[y, x] (y = แถว, x = คอลัมน์)

2 · Resolution (ความละเอียด)

Resolution = จำนวนพิกเซลทั้งหมด = กว้าง (W) × สูง (H) — เช่น 1920×1080 = 2,073,600 พิกเซล

⚠ DCI 4K (4096×2160) ≠ 4K UHD (3840×2160)

3 · Color Depth (บิตต่อพิกเซล)

จำนวนค่าที่เป็นไปได้ = 2บิต — ยิ่งบิตมาก ยิ่งมีสี/ระดับเทามาก

  • 8 bit = 256 เพราะ 00000000–11111111 = 0–255 (พอดี uint8 ใน OpenCV)
  • RGB565 (16-bit High Color): แดง 5 (32) + เขียว 6 (64) + น้ำเงิน 5 (32) → 32×64×32 = 65,536 สี — เขียวได้เยอะเพราะ ตาคนไวต่อสีเขียวที่สุด · ใช้จอเก่า/มือถือยุคแรก (ประหยัดหน่วยความจำ)
  • 24-bit True Color: 256×256×256 = 16,777,216 ≈ 16.7 ล้านสี · 1 พิกเซล = 3 ไบต์ · ตาแยกแทบไม่ออก
  • 32-bit RGBA: RGB 24 + Alpha 8 บิต (ความโปร่งใส) — Alpha 0 = โปร่งใส (มองทะลุ) · 128 = ครึ่ง · 255 = ทึบ · ใช้ PNG โปร่งใส / ซ้อนภาพ / watermark

4 · ขนาดไฟล์ภาพ

ขนาด (ไบต์) = W × H × บิตต่อพิกเซล ÷ 8 — ค่านี้คือขนาด ดิบ (raw) ยังไม่บีบอัด

  • โจทย์: grayscale 8-bit 100×100 → 10,000 พิกเซล × 1 B = 10,000 B
  • Full HD 24-bit → 2,073,600 × 3 B = 6,220,800 B ≈ 6.2 MB
  • Full HD 8-bit → 2,073,600 B ≈ 2.07 MB
  • ไฟล์จริง (JPEG/PNG) เล็กกว่าค่าที่คำนวณ เพราะถูก บีบอัด

5 · ประเภทของภาพ (Image Types)

  • Binary — 1 บิต/พิกเซล · ค่า 0 (ดำ) / 1 (ขาว) เท่านั้น · เป็นผลลัพธ์ของ Threshold / Segmentation (แยก object–background)
  • Grayscale — เก็บแค่ ความเข้ม 1 ช่อง · 8-bit = 0–255 (256 ระดับ) · อัลกอริทึมหลายตัวทำงาน 1 ช่อง (เร็ว/ง่ายกว่า) · cv2.imread(img, 0) หรือ cvtColor(...COLOR_BGR2GRAY)
  • Color — 1 พิกเซล = 3 ช่อง (RGB หรือ BGR) · 24-bit = 3 ไบต์ · shape = (H, W, 3)
  • Multispectral — เก็บ หลาย band (ช่วงคลื่น) เกิน 3 แถบ (RGB มีแค่ 3) · ดาวเทียม / รีโมตเซนซิ่ง / การเกษตร — NIR บอกสุขภาพพืชได้ (ตา/ภาพ RGB มองไม่เห็น)

6 · Color Models (ระบบสี)

Color Model / Color Space = วิธีแทนสีด้วยตัวเลข · สีเดียวกันแปลงระหว่างระบบได้ (cvtColor) · แต่ละระบบเหมาะกับงานต่างกัน

  • RGB — additive (รวมแสง) · ใช้กับจอภาพ · ขาว = R+G+B ครบ, ดำ = ไม่มีแสง · แดง+เขียว=เหลือง · แดง+น้ำเงิน=ม่วง · เขียว+น้ำเงิน=ฟ้า · OpenCV เรียง BGR (แดง-น้ำเงินสลับถ้าโชว์ด้วย Matplotlib โดยไม่แปลง → ใช้ COLOR_BGR2RGB)
  • CMYK — subtractive (ลบแสง) · ใช้กับเครื่องพิมพ์/งานสิ่งพิมพ์ · Cyan, Magenta, Yellow, Key(Black) · เริ่มจากกระดาษขาว หมึกดูดกลืนแสง · C+M+Y = ดำคล้ำ → ใช้ K แทนเพื่อประหยัดหมึก
  • HSL / HSV — Hue (สี, องศา 0–360°: 0°=แดง, 120°=เขียว, 240°=น้ำเงิน) · Saturation (ความสด, %; 0 = เทา) · Lightness/Value (ความสว่าง, %)
  • HSL vs HSV ต่างกัน: HSL L=100% → ขาวเสมอ (จาง) แต่ HSV V=100% → สีสดเต็ม (ไม่จาง) — HSV นิยมในคอมกราฟิก/UI · จำ: L เพิ่ม→ใกล้ขาว, V เพิ่ม→สีสด, S ลด→ซีด/เทา
  • LAB — L = Lightness (แยกความสว่างออกจากสี) · a = เขียว(−)→แดง(+) · b = น้ำเงิน(−)→เหลือง(+) · นิยมวิเคราะห์/เทียบสี (ใกล้เคียงการมองของคน)
  • YCrCb — Y = Luminance (ความสว่าง) · Cr = แดง−L · Cb = น้ำเงิน−L · ใช้ในวิดีโอ/ทีวี (JPEG, MPEG) — ตาไวต่อความสว่างเลยให้ Y เยอะ
  • จุดร่วม LAB / YCrCb: แยกความสว่างออกจากสี → เทคนิค equalize ภาพสีมักทำที่ช่อง L / Y เท่านั้น

7 · สูตร & เลขต้องจำก่อนเข้าห้องสอบ

  • จำนวนพิกเซล = W × H · จำนวนสี = 2บิต · ขนาดไฟล์ = W×H×บิต÷8 ไบต์
  • 8 bit = 1 B · 24 bit = 3 B · 32 bit = 4 B ต่อพิกเซล
  • 1 Hex digit = 4 บิต · 210 ≈ 1,024 · 220 ≈ 1 ล้าน
  • 565 → High Color 16-bit = 65,536 สี · 888 → True Color 24-bit = 16.7 ล้าน · RGBA = 24+8
  • 720p = 1280×720 · 1080p = 1920×1080 · 2160p = 3840×2160 (p = ความสูง)
  • OpenCV: BGR · img[y, x] · uint8 0–255 · cvtColor แปลงสี

8 · กับดักที่ข้อสอบชอบหลอก (ระวังให้ดี)

  • ⚠ 16-bit = 65,536 สี แต่ 24-bit = 16.7 ล้าน — อย่าสลับกัน
  • ⚠ Binary (2 ค่า: 0/1) ≠ Grayscale (256 ค่า: 0–255)
  • ⚠ DCI 4K = 4096×2160 ≠ 4K UHD = 3840×2160
  • ⚠ OpenCV ใช้ BGR ไม่ใช่ RGB
  • ⚠ HSL L=100% → ขาว แต่ HSV V=100% → สีสด (ต่างกัน!)
  • ⚠ Alpha: 0 = โปร่งใส, 255 = ทึบ — อย่าจำสลับ
  • ⚠ ขนาดไฟล์ที่คำนวณได้ = raw ก่อนบีบอัด (ไฟล์จริงเล็กกว่า)
  • ⚠ Multispectral = หลาย band เกิน 3 (RGB แค่ 3)
  • ⚠ RGB = additive (จอ, เริ่มดำ) vs CMYK = subtractive (พิมพ์, เริ่มขาว)

9 · คำถาม-คำตอบฉบับเร็ว (จากแบบทดสอบบทนี้)

  • 1920×1080 มีกี่พิกเซล? → 2,073,600 (W×H)
  • Full HD (1080p) คือ? → 1920×1080
  • 8-bit grayscale กี่ระดับเทา? → 2⁸ = 256 (0–255)
  • 24-bit True Color กี่สี? → 2²⁴ = 16,777,216 (16.7 ล้าน)
  • Binary 1 พิกเซลมีค่าได้กี่ค่า? → 2 (0 หรือ 1)
  • RGB565 ช่องเขียวกี่บิต? → 6 (R5 G6 B5, 16 บิต, 65,536 สี)
  • RGBA ตัว A คือ? → Alpha = ความโปร่งใส (0 โปร่งใส, 255 ทึบ)
  • ภาพแบบไหนพิกเซลเป็น 0/1 เท่านั้น? → Binary Image
  • OpenCV เรียงช่องสีแบบใด? → BGR (ต้อง cvtColor ก่อนแสดง)
  • งานพิมพ์ใช้ระบบสีใด? → CMYK (subtractive)
  • 640×480 กี่พิกเซล? → 307,200 (VGA)
  • 4K UHD (2160p) คือ? → 3840×2160 (DCI 4K = 4096×2160)
  • ภาพ 2-bit กี่สี? → 2² = 4
  • 16-bit High Color กี่สี? → 2¹⁶ = 65,536
  • Grayscale 8-bit พิกเซลอยู่ในช่วง? → 0–255 (0=ดำ, 255=ขาว)
  • Multispectral คือ? → ภาพหลาย band เกิน 3 แถบ (ดาวเทียม/รีโมตเซนซิ่ง)
