Sampling (สุ่มตัวอย่าง)

ภาพ f(x,y) ต้องถูก digitize ทั้งเชิงพื้นที่ (sampling) และเชิง amplitude (quantization) ถึงจะเป็นภาพดิจิทัล

Sampling คืออะไร

EXPERIMENT 1 · 2/2

Quantization (ควอนไทซ์)

แปลงค่าความเข้มต่อเนื่องให้เป็นดิจิทัล — กำหนดจำนวน grey levels ของภาพ

Quantization คืออะไร

ปัดค่าความเข้ม (amplitude) ให้เป็นระดับไม่ต่อเนื่อง → quantization level กำหนดจำนวน grey levels

⚠ False Contours

ภาพที่ quantize ด้วยระดับความสว่าง ไม่เพียงพอ จะเกิดเส้นขั้นบันได (false contours) บนพื้นผิวเรียบ

Uniform Quantization — แบ่ง 0–255 เป็น 16 ช่วง ช่วงละ 16
for i=1:m for j=1:n if a(i,j)<16 a(i,j)=7; elseif a(i,j)<32 a(i,j)=23; ... else a(i,j)=247; end end end
🧮 จับมือ พิกเซลค่าระหว่าง 0–15 → 7 · 16–31 → 23 · 32–47 → 39 … ค่าใหม่คือ จุดกึ่งกลางช่วง (midpoint) ของแต่ละช่วง
Exam TipQuantization เกี่ยวกับ ค่า (amplitude) → กำหนด grey levels · แบ่งช่วงแล้วแทนด้วยจุดกึ่งกลาง

EXPERIMENT 3 · 2/3

Gamma Transformation

s = c·r^γ — ปรับความสว่างด้วยเลขชี้กำลัง γ

ค่า γ ต่างกันยังไง

• γ < 1 → brighten (ภาพมืดสว่างขึ้น)
• γ > 1 → darken (ภาพสว่างมืดลง)
• γ = 1 → คงเดิม

J = imadjust(I,[],[],0.4); % γ=0.4 สว่าง J = imadjust(I,[],[],3); % γ=3 มืด
Exam Tipจำ: γ<1 = สว่าง · γ>1 = มืด — ข้อสอบชอบพลิกถามสองอันนี้

EXPERIMENT 3

Log & Contrast Stretching

อีกรูปแบบของ intensity transformation — เหมาะกับภาพที่มืดหรือ contrast ต่ำ

Log Transformation

s = c·log(1+r)

แมปช่วงค่าต่ำ (dark) ที่แคบไปเป็นช่วงกว้าง และบีบอัดค่าสูง → expand dark pixels

d = im2double(tire); c = 1/log(1+255); j = c*log(1+d*255);

Contrast Stretching (sigmoid)

สูตร: s = 1 / (1 + (m/(r+ε))^E)
• E (Exponent) — ความชันของ curve: E ใหญ่ = ตัด contrast แรง
• m — จุดกึ่งกลาง (threshold) ที่ curve พลิก

🧮 จับมือ E = 4, 5, 10 → ยิ่ง E สูง curve ยิ่งชัน → ค่าที่ต่ำกว่า m ถูกกดให้ดำ ค่าที่สูงกว่า m ถูกดันให้ขาว (contrast เพิ่ม)
🧮 จับมือ เปลี่ยน m = 0.2, 0.5, 0.7 → จุดที่ "พลิก" ขยับ — เลือก m ให้ตรงกับระดับเทาที่สนใจ
Exam Tipcontrast stretching = เพิ่ม contrast ระหว่าง dark/light — ปรับได้ 2 ค่า: E (ความชัน) และ m (จุดพลิก)

EXPERIMENT 4

DFT Analysis — frequency domain

Fourier Transform แยกภาพออกเป็น sine และ cosine components — แต่ละจุดใน frequency domain แทนความถี่ที่อยู่ในภาพ

4 อย่างที่ Ex4 ทำ

• fft2 → ภาพไป frequency domain
• abs(F) = magnitude plot (ความแรงของแต่ละความถี่)
• angle(F) = phase plot (ตำแหน่งของคลื่น)
• ifft2 → กลับมา spatial domain ได้ภาพเดิม

Rotation Property

หมุนภาพ 90° → FFT ก็หมุนตาม 90° ด้วย (สเปกตรัมหมุนตามภาพต้นทาง)

ขนาด DFT = ขนาดภาพเดิม
b=im2double(a); c=fft2(b); % ไป freq d=ifft2(c); % กลับมา mag=abs(c); % magnitude ang=angle(c); % phase

จำนวนความถี่ = จำนวนพิกเซล → ภาพทั้ง 2 domain ขนาดเท่ากัน

Exam Tipfft2 = ไปข้างหน้า · ifft2 = ย้อนกลับ · abs = magnitude · angle = phase · DFT มีขนาดเท่าภาพต้นทาง

EXPERIMENT 5

Walsh & Hadamard Transform

Transform ที่ใช้เลข ±1 (binary) แทนฟังก์ชัน sine/cosine — คำนวณด้วย matrix เดียวกันทั้งไปและกลับ

ไอเดียของทั้งคู่

สร้าง matrix f ขนาด N×N ที่มีแต่ค่า ±1 โดยใช้เลข binary ของตำแหน่ง (x, u) แล้วคำนวณ

F = (1/N) · f · a · f

ใช้ f ตัวเดิมคูณทั้ง 2 ด้าน — ต่างกันแค่ลำดับการพลิกบิต:
Walsh ใช้ p(n+1-i)·q(i) · Hadamard ใช้ p(n+1-i)·q(n+1-i)

ขั้นตอน (เหมือนกันทั้งคู่)

1. สร้าง f จาก binary ของ index
2. F = (1/N)·f·a·f
3. สลับ quadrant ให้สเปกตรัมอยู่กลาง (fftshift แบบ manual)
4. ดู log(1+|F|) เพื่อให้เห็นความถี่

ต่างกันนิดเดียวWalsh vs Hadamard — ต่างที่วิธีการสร้าง matrix f (การเรียงลำดับของแถว) แต่ผลที่เห็นคล้ายกัน

EXPERIMENT 5

DCT & Haar Transform

สอง transform ที่เหลือของ Ex5 — ใช้จริงใน JPEG (DCT) และ compression (Haar)

DCT — Discrete Cosine Transform

ใช้ cosine basis แทน sine — ใช้กับสัญญาณจริง (real) โดยตรง ไม่มีส่วนจินตภาพ

F = dct2(double(a)); % 2-D DCT

⭐ ใช้จริงในมาตรฐาน JPEG — แปลง block 8×8 แล้วทิ้งค่าความถี่สูง

Haar Transform

basis function เป็น ฟังก์ชันขั้น (step ±) ขนาดต่าง ๆ — แบ่งภาพเป็นส่วนละเอียด/หยาบ ตามกำลังของ 2

p=fix(log2(i)); % หา scale F = f*a*f; % f มีค่า 0/±2^(p/2)

⭐ ใช้ใน wavelet / image compression — แยก detail ระดับต่าง ๆ

จำแบบนี้Walsh/Hadamard = ±1 binary · DCT = cosine (ใช้ใน JPEG) · Haar = step (ใช้ใน wavelet) — ทั้ง 4 เป็นการเปลี่ยนมุมมองภาพไปอีก "domain"

EXPERIMENT 6 · 1/2

Histogram (ฮิสโตแกรม)

Histogram = การกระจายของ grey levels ในภาพ — บอกภาพมืด/สว่าง/contrast ต่ำ ได้จากรูปร่าง

Histogram: P(rk) = nk / n

nk = จำนวนพิกเซลที่มี grey value rk · n = พิกเซลทั้งหมด

Histogram บอกอะไร

• Histogram รวมซ้าย (ค่าต่ำ) → ภาพมืด
• รวมขวา (ค่าสูง) → ภาพสว่าง
• แคบตรงกลาง → ภาพcontrast ต่ำ

Exam TipP(rk) = nk/n — nk = จำนวนพิกเซลที่มี grey value rk · n = พิกเซลทั้งหมด

EXPERIMENT 6 · 2/2

Histogram Equalization

ออกแบบ transformation T(.) ให้ grey values กระจายสม่ำเสมอ — ภาพ contrast ดีขึ้น

หลักการ

ทำให้ grey values ใน output กระจาย uniform ใน [0,1] — ทุก grey value มีสัดส่วนเท่ากัน → ภาพ contrast ดีขึ้น (ใช้พื้นที่ทั้งช่วง)

EXPERIMENT 8

Frequency Domain Fundamentals

กรองใน frequency domain = แก้ FFT ของภาพ แล้ว inverse กลับมา — สมการหัวใจของทั้งบทนี้

g(x,y) = F⁻¹[ H(u,v) · F(u,v) ]

F(u,v) = DFT ของภาพ input f(x,y) · H(u,v) = filter function · F⁻¹ = IDFT → g(x,y) = ภาพ output

Lowpass (LPF) คงความถี่ต่ำ ตัดความถี่สูง → ใน spatial = smoothing
Highpass (HPF) คงความถี่สูง ตัดความถี่ต่ำ → ขอบมี high freq → edge enhancement
Bandpass คงช่วงกลาง ตัดต่ำ-สูงมาก → enhance ขอบ + ลด noise พร้อมกัน
Exam TipLPF = smoothing (ตัด high) · HPF = edge (ตัด low) — ในสมการ H(u,v) คือ filter function

EXPERIMENT 8

3 Lowpass Filters: Ideal · Butterworth · Gaussian

ความถี่แต่ละจุดอยู่ห่างจากศูนย์กลาง D(u,v) = √[(u−M/2)² + (v−N/2)²] — ตัดตามระยะ D₀

Ideal H=1 ถ้า D≤D₀
H=0 ถ้า D>D₀ ตัดแบบ "คม" ขาด → เกิด ringing
Butterworth H = 1/(1+(D/D₀)^2n) order n ควบคุมความชัน — นุ่มกว่า ideal
Gaussian H = e^(−D²/2σ²) เรียบที่สุด ไม่มี ringing
% สร้าง Butterworth LPF ขนาดเท่าภาพ แล้วคูณกับ FFT d(i,j) = sqrt((i-x).^2+(j-y).^2); h(i,j) = 1/(1+((d(i,j))/rad).^(2*N)); fft1 = fftshift(fft2(img)); fil = h.*fft1; fin = ifft2(fil);
Highpass = 1 − Lowpass — H_hp(u,v) = 1 − H_lp(u,v) · สลับจาก "ผ่านต่ำ" เป็น "ผ่านสูง" ได้ทันที

EXPERIMENT 9

Edge Detection — 4 Operators

ขอบ = ตำแหน่งที่ระดับเทาเปลี่ยนเร็ว — ใช้ gradient (การประมาณอนุพันธ์) ของความเข้มภาพ

Sobel gradient แนวนอน/แนวตั้ง integer mask — นิยมใช้สุด
Prewitt คล้าย Sobel แต่ mask ต่างกันเล็กน้อย
Roberts 2×2 — ใช้ผลต่างแนวทแยง (diagonal) ขนาดเล็กสุด
Canny multi-stage algorithm — ตรวจจับขอบได้หลากหลาย (optimal: derivative ของ Gaussian)
[g,t]=edge(f,'sobel','vertical'); % ขอบแนวตั้ง [g,t]=edge(f,'sobel','horizontal'); % ขอบแนวนอน [g,t]=edge(f,'sobel','both'); % ทั้งสองทิศ
Exam Tip4 operators: Sobel · Prewitt · Roberts · Canny — Canny คือ multi-stage ที่แม่นที่สุด

EXPERIMENT 10 · 1/2

Erosion & Dilation

operation พื้นฐาน 2 ตัวของ Morphology — ใช้ structuring element (strel) กำหนดรูปร่าง

Dilation เพิ่มพิกเซลที่ขอบ — ขยายวัตถุ
Erosion ลบพิกเซลที่ขอบ — กร่อนวัตถุ
b = strel('disk',10); % structuring element c = imdilate(a,b); % dilation → ขยาย c = imerode(a,b); % erosion → กร่อน

Structuring Element (strel)

ขนาดและรูปร่างของ neighborhood เป็นตัวกำหนดว่าจะเพิ่ม/ลบกี่พิกเซล — 'disk', 'square', 'line'…

Exam Tipdilate = เพิ่มขอบ (ขยาย) · erode = ลบขอบ (กร่อน) — จำง่าย: ขยาย = + พิกเซล, กร่อน = − พิกเซล

EXPERIMENT 10 · 2/2

Opening & Closing

ผสม Erosion + Dilation เข้าด้วยกัน 2 แบบ — ใช้จัดรูปวัตถุ

Opening erode แล้ว dilate — ลบจุดเล็ก/เส้นเล็ก
Closing dilate แล้ว erode — เติมรู/ช่องว่างเล็ก
c = imopen(a,b); % opening = erode→dilate c = imclose(a,b); % closing = dilate→erode c = bwmorph(b,'thin'); % ผอมเส้น

bwmorph — ตัวช่วย

'remove' · 'clean' · 'shrink' · 'fill' · 'thin' · 'thick' — operation สำเร็จรูปสำหรับ binary image

Exam Tipopen = erode→dilate (ลบจุดเล็ก) · close = dilate→erode (เติมรูเล็ก) — จำลำดับให้ตรง

EXPERIMENT 11

Region-based Segmentation: Thresholding

วิธี segmentation ที่ง่ายสุด: เลือกค่า T แล้วแบ่งพิกเซลเป็น object / background

รูปแบบทั่วไปของ Threshold

T = T[x, y, p(x,y), f(x,y)]
Global T ขึ้นกับ f(x,y) เท่านั้น — ค่าคงที่ทั้งภาพ
Local T ขึ้นกับ f + local properties p(x,y) (เช่น ค่าเฉลี่ยรอบข้าง)
Dynamic / Adaptive T ขึ้นกับพิกัด (x,y) ด้วย — เปลี่ยนตามตำแหน่ง

เมื่อไหร่ใช้ global ได้

เมื่อ histogram มี 2 ยอด (bimodal) แยกชัด — แต่ละยอดแทน background / object แบ่งตรงหุบระหว่างยอด

Otsu's Method (graythresh)

หา threshold อัตโนมัติ ที่แบ่ง histogram ให้สองกลุ่มแยกกันมากที่สุด

level=graythresh(a); b=im2bw(a,level);
ตัวอย่าง bimodal histogram

ยอดซ้าย = background (มืด) · ยอดขวา = object (สว่าง) · T อยู่ตรงหุบ

Exam TipGlobal = ขึ้นกับ f เท่านั้น · Local = +p(x,y) · Dynamic = ขึ้นกับ (x,y) · Otsu = graythresh หา T อัตโนมัติ

EXPERIMENT 12 · 1/2

RGB = M×N×3 — Component Images

ภาพ RGB เป็น stack 3 ชั้น — แยกดูทีละช่องสีได้

RGB = stack 3 ชั้น

• ภาพ RGB = array M×N×3 — แต่ละพิกเซล = triplet (R,G,B)
• component images: R=a(:,:,1) · G=a(:,:,2) · B=a(:,:,3)
• ปิดช่องอื่นให้ 0 → เห็นแค่ช่องสีเดียว

a(:,:,2)=0; a(:,:,3)=0; % เหลือ R

Colormap

matrix m×3 (ค่า 0–1) — แต่ละแถว = สี 1 สี: copper · jet · summer · gray…

imshow(a,copper); % ย้อมภาพเทา
Exam TipRGB = M×N×3 · แยกช่องด้วย a(:,:,k) · ใช้ colormap ย้อมภาพเทา

EXPERIMENT 12 · 2/2

แปลง Color Space

เปลี่ยนโมเดลสีเพื่อให้เหมาะกับงาน — luminance/chrominance แยกกัน

🟡 rgb2ntsc — YIQ: luminance (Y) + chrominance (I, Q)
🟢 rgb2ycbcr — YCbCr: Y = luminance แบบ NTSC + Cb/Cr
🔵 rgb2hsv — H = Hue, S = Saturation, V = Brightness (ตรงกับวิธีคนมองสี)
🔄 imcomplement — กลับสี (negative ของภาพสี)
Exam TipNTSC/YCbCr = luminance+chrominance · HSV = Hue/Saturation/Value — จำคู่ฟังก์ชันให้ตรง
