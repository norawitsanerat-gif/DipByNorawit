1 · Segmentation คืออะไร

  • Segmentation = แบ่งภาพออกเป็นส่วน ๆ — แยก "วัตถุ (object)" ออกจาก "พื้นหลัง (background)"
  • Pipeline: Camera → Enhancement (บท 4) → Filter (บท 5) → Threshold/Segmentation (บทนี้) → Contour → Detection
  • ก่อนนับ/วัด/ตรวจจับอะไร ต้องรู้ก่อนว่า "ตรงไหนคือตัววัตถุ" — segmentation คือก้าวแรก · วิธีง่ายสุด = Threshold (แบ่งด้วยค่าความเข้ม)

2 · Threshold — 5 โหมด (cv2.threshold)

  • Global Threshold = ค่าขีด (thresh) หนึ่งเดียวใช้ทั้งภาพ — ret, binary = cv2.threshold(gray, 128, 255, cv2.THRESH_BINARY) (thresh = 128, maxval = 255)
โหมดต่ำกว่า tสูงกว่า tตัวอย่าง (100 / 150, t=128)
THRESH_BINARY0maxval (255)0 / 255
THRESH_BINARY_INV2550255 / 0 (กลับด้าน)
THRESH_TRUNCค่าเดิมตัด = t100 / 128 (ล็อกค่าบน)
THRESH_TOZERO0ค่าเดิม0 / 150
THRESH_TOZERO_INVค่าเดิม0100 / 0
  • INV = INVerse = เอาสีสลับ — ใช้เมื่อวัตถุมืดกว่าพื้นหลัง (กลับให้วัตถุเป็นขาวก่อนทำงานต่อ)
  • TRUNC ใช้ลบ highlight · TOZERO = "เก็บของที่ผ่านขีด โละของที่ต่ำกว่า"
  • ผลลัพธ์ = ภาพ binary (0 กับ 255) — เหมาะภาพแสงสม่ำเสมอ พื้นหลังชัด

3 · Global vs Adaptive vs Otsu

  • ปัญหา Global: ภาพแสงไม่สม่ำเสมอ (gradient/เงา/แดดส่องบางส่วน) → ขีดเดียวตัดพลาดเสมอ (ขีดสูง: ฝั่งมืดดำหมด · ขีดต่ำ: ฝั่งสว่างตัวหนังสือหาย) → ต้อง Adaptive หรือ Otsu
  • Adaptive Threshold = คำนวณขีดใหม่ทุกตำแหน่งจาก neighborhood (sliding window) — ฝั่งสว่างได้ขีดสูง ฝั่งมืดได้ขีดต่ำ · ใช้กับสแกนเอกสาร/OCR
  • โค้ด: cv2.adaptiveThreshold(img, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, 11, 2)
  • อ่านพารามิเตอร์ 2 ตัวท้าย: 11 = blockSize (ขนาด window 11×11 ใช้คำนวณขีด — ต้องเลขคี่, ใหญ่ = ขีดเนียนแต่ช้า) · 2 = ค่าคงที่ C (ลบออกจากขีด — ปรับความไว กัน noise ถูกตัดเป็นขาว)
  • Otsu = หาขีดที่ดีที่สุดอัตโนมัติจาก histogram (ลองทุกค่า 0–255 เลือกที่แยก 2 กลุ่มได้ห่างสุด) — เหมาะ histogram 2 ยอด (bimodal) · ใช้ flag cv2.THRESH_BINARY + cv2.THRESH_OTSU ส่ง 0 แทน thresh · ค่าขีดที่หาได้คืนใน ret
วิธีขีดเหมาะกับจุดอ่อน
Global1 ค่าทั้งภาพแสงสม่ำเสมอแสงไม่เท่ากัน → ตัดพลาด
Adaptiveเปลี่ยนตามตำแหน่ง (local)แสงไม่สม่ำเสมอ, OCR, สแกนช้ากว่า, มี parameter
Otsuหาอัตโนมัติ 1 ค่าhistogram 2 ยอดชัดเจนแสงไม่สม่ำเสมอ ยังพัง

เลือกยังไง: แสงดี → Global · แสงไม่เท่ากัน → Adaptive · ไม่รู้ค่าขีด + histogram 2 ยอด → Otsu

4 · Morphology — ปรับรูปร่างภาพ binary

  • Morphology = ปรับ "รูปร่าง" ของวัตถุในภาพ binary ด้วย kernel (structuring element) — ลบจุด noise, ปิดรู, ต่อรอยขาด, ทำให้ contour สวย
  • Erosion (กร่อน/หด): เก็บพิกเซลกลางก็ต่อเมื่อทุกช่องใต้ kernel เป็นขาว (AND/min) → วัตถุเล็กลงรอบด้าน + ลบจุด noise เล็ก (เล็กกว่า kernel หายทั้งจุด) · cv2.erode(binary, kernel)
  • Dilation (ขยาย): กลางเป็นขาวเมื่อมีขาวอย่างน้อย 1 จุดใต้ kernel (OR/max) → ขอบขยายออกทุกทิศ ใช้ปิดรู/เชื่อมรอยขาด · cv2.dilate(binary, kernel)
  • Opening = Erosion → Dilation (เริ่ม E ลบจุด noise ขาวเล็ก โดยไม่หดวัตถุใหญ่) · Closing = Dilation → Erosion (เริ่ม D ปิดรู/รอยขาดดำ โดยไม่ขยายวัตถุใหญ่)
  • โค้ด: cv2.morphologyEx(b, cv2.MORPH_OPEN, kernel) / cv2.MORPH_CLOSE
  • จำ: Opening = เริ่มด้วย Erosion (ลบจุดเล็ก) · Closing = เริ่มด้วย Dilation (ปิดรู) — เริ่มจากตัวแรกเป็นตัวหลัก

5 · Contour & Bounding Box

  • Contour = เส้นขอบที่ลากรอบวัตถุ (เส้นโค้งเชื่อมจุดขอบเดียวกัน) — ใช้บอกตำแหน่ง/รูปร่าง · Edge = จุดที่ความเข้มเปลี่ยน (พิกเซล) แต่ Contour = เส้นปิดรอบวัตถุทั้งชิ้น (โครงสร้าง)
  • Pipeline: Threshold → Morphology (ลบ noise) → findContours (หาวัตถุ) → นับ/วัด/ตรวจจับ
  • cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE) → contours, hierarchy · รับภาพ binary · RETR_EXTERNAL = เอาเฉพาะขอบนอกสุด · CHAIN_APPROX_SIMPLE = เก็บเฉพาะมุม (ประหยัดหน่วยความจำ) · len(contours) = นับวัตถุ
  • Bounding Box: x, y, w, h = cv2.boundingRect(cnt) — สี่เหลี่ยมที่เล็กที่สุดครอบ contour (axis-aligned) · x, y = มุมซ้ายบน · เอาไป crop / วาดกรอบ / วัดขนาดจริง (พิกเซล → mm เทียบสเกล)
  • วาด: cv2.drawContours(img, contours, -1, (0,255,0), 2) · cv2.rectangle(img, (x,y), (x+w,y+h), (0,255,0), 2)

6 · Feature Extraction — Shape · Corner · Descriptor

  • แปลง "รูปร่างของวัตถุ" เป็นตัวเลข (features) ที่เครื่องคำนวณ/เปรียบเทียบได้ — เป็น input ของ ML/การจำแนก
  • Shape: area = cv2.contourArea(cnt) (พื้นที่) · peri = cv2.arcLength(cnt, True) (เส้นรอบรูป) · moments = cv2.moments(cnt) → จุดศูนย์ถ่วง cx = m10/m00, cy = m01/m00
  • แยกวงกลม vs สี่เหลี่ยมด้วยอัตราส่วน area/perimeter (วงกลม area ≈ πr², peri ≈ 2πr · สี่เหลี่ยม area = w·h)
  • Corner Detection: มุม = จุดที่เลื่อนนิดเดียวค่าพิกเซลเปลี่ยนทุกทิศ (จดจำง่าย ไม่กำกวม — ขอบเปลี่ยนแค่ทิศเดียว, พื้นเรียบไม่มีข้อมูล) · Harris = cv2.cornerHarris(gray, 2, 3, 0.04) (คะแนนทุกจุด) · Shi-Tomasi = cv2.goodFeaturesToTrack(gray, 50, 0.01, 10) (คืนเฉพาะ N จุดดีที่สุด)
  • Feature Descriptor: เลขบรรยาย "หน้าตา" รอบจุดเด่น — kp, des = orb.detectAndCompute(gray, None) · SIFT = แม่นยำสูง (ช้า, จดสิทธิบัตร) · SURF = SIFT เวอร์ชันเร็ว · ORB = ฟรี+เร็ว เหมาะมือถือ/เรียลไทม์ · ใช้จับคู่ภาพ (matching) / สร้าง panorama (stitching)

7 · Geometric Transform — Resize · Rotate · Perspective

  • Resize = ย่อ/ขยาย: cv2.resize(img, (640, 480)) — สำคัญกับ AI เพราะ CNN รับขนาดคงที่ (เช่น 224×224) ต้อง resize ให้เท่ากันก่อน
  • Rotate = หมุน 90° ทวีคูณ: cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE) · Translate = เลื่อนด้วยเมทริกซ์ + cv2.warpAffine(img, M, (w, h))
  • Affine = เลื่อน/หมุน/ย่อ (เส้นขนานยังขนาน) · Perspective = แก้ภาพเอียง/เบี้ยวด้วย 4 มุม (เส้นอาจไม่ขนาน) — สแกนเอกสาร
  • Perspective workflow: หา 4 มุมเอกสาร (เช่น จาก contour) → M = cv2.getPerspectiveTransform(pts_src, pts_dst) → scanned = cv2.warpPerspective(img, M, (w, h)) — ได้ภาพตรงเหมือนสแกน (CamScanner)

8 · Advanced & Computer Vision + AI

  • Image Restoration = กู้ภาพที่เสีย: Deblur (แก้เบลอจากมือสั่น/โฟกัสพลาด) + Denoising (ลบ noise — ต่อจากบท 5) + ใช้ Fourier (บท 5) กรองแบบความถี่
  • Image Stitching = ต่อภาพหลายใบเป็นภาพพาโนรามา — ใช้ feature matching (SIFT/ORB) หาจุดที่ตรงกัน + perspective ต่อภาพ
  • วิวัฒนาการ CV: Classic CV (กฎเขียนด้วยมือ: threshold+contour+feature) → ML (feature ด้วยมือ + classifier: SVM/Random Forest) → DL/CNN (เรียนรู้ feature เองจากภาพตรง ๆ — ไม่ต้องออกแบบ feature) · Framework: PyTorch · TensorFlow
  • CNN = Convolutional Neural Network — โครงข่ายที่ใช้ convolution (kernel!) หลายชั้น เรียนรู้ค่าน้ำหนักเองจากข้อมูล
โมเดลตรวจจับวัตถุแนวคิดจุดเด่น
YOLOดูทั้งภาพครั้งเดียว (one-stage)เร็วมาก — เรียลไทม์
SSDSingle Shot — ตรวจจับหลายขนาดครั้งเดียวเร็ว + แม่นยำสมดุล
Faster R-CNNสองขั้นตอน: เสนอพื้นที่ → จำแนกแม่นยำสูงสุด แต่ช้า

Output ของ object detection = bounding box (x, y, w, h) + class + confidence (เช่น "person 0.95") — เหมือน boundingRect ที่เรียนมา

9 · สูตร & คำสั่งต้องจำก่อนเข้าห้องสอบ

  • BINARY: ≥t → 255 · INV = สลับ · TRUNC = ตัดเกิน · TOZERO = ต่ำกว่า → 0
  • adaptiveThreshold(..., blockSize, C) — 11 = window 11×11 (เลขคี่) · 2 = ค่าคงที่ C
  • Otsu: cv2.THRESH_BINARY + cv2.THRESH_OTSU (ส่ง 0, ค่าขีดใน ret) · เหมาะ histogram 2 ยอด
  • Erosion = หด (AND/min) · Dilation = ขยาย (OR/max) · Opening = E→D (ลบจุดเล็ก) · Closing = D→E (ปิดรู)
  • findContours(binary, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE) → นับด้วย len()
  • boundingRect → (x, y, w, h) · contourArea = พื้นที่ · arcLength = เส้นรอบรูป · moments = จุดศูนย์ถ่วง (m10/m00)
  • Corner: Harris (cornerHarris) · Shi-Tomasi (goodFeaturesToTrack) · Descriptor: SIFT/SURF/ORB
  • Resize/Rotate/warpAffine (affine) · warpPerspective แก้เอียง 4 มุม (สแกนเอกสาร)
  • YOLO = เร็ว · Faster R-CNN = แม่น · CNN เรียนรู้ feature เอง

10 · กับดักที่ข้อสอบชอบหลอก

  • ⚠ THRESH_BINARY: ≥ t → 255 (ไม่ใช่ค่าต่ำกว่าเป็น 255)
  • ⚠ TRUNC = ตัดค่าสูง · TOZERO = โละค่าต่ำ — อย่าสลับ
  • ⚠ Adaptive = local (ขีดต่อ pixel) · Global = 1 ค่าทั้งภาพ
  • ⚠ 11 = blockSize (เลขคี่) · 2 = ค่าคงที่ C — ไม่ใช่ threshold/iteration
  • ⚠ Opening = erode→dilate (ลบจุดขาวเล็ก) · Closing = dilate→erode (ปิดรูดำ) — อย่าจำสลับ
  • ⚠ erode = หด (ทุกช่องต้องขาว/AND) · dilate = ขยาย (มีขาวจุดเดียวพอ/OR)
  • ⚠ findContours รับภาพ binary (หลัง threshold) — ไม่ใช่ภาพสี/grayscale ตรง ๆ
  • ⚠ RETR_EXTERNAL = ขอบนอกสุด · CHAIN_APPROX_SIMPLE = เก็บมุม
  • ⚠ Otsu เหมาะ histogram 2 ยอด — แสงไม่สม่ำเสมอ Otsu ก็พัง (ต้อง Adaptive)
  • ⚠ YOLO = เร็ว · Faster R-CNN = แม่น — ไม่ใช่กลับกัน
  • ⚠ SIFT = แม่น/ช้า · ORB = ฟรี/เร็ว · SURF = เร็ว (กลาง ๆ)
  • ⚠ Edge ≠ Contour — Edge = จุดเปลี่ยนความเข้ม · Contour = เส้นปิดรอบวัตถุ

11 · คำถาม-คำตอบฉบับเร็ว (จากแบบทดสอบบทนี้)

  • Thresholding ใช้ทำอะไร? → แยก object ออกจาก background (ภาพขาว-ดำ)
  • THRESH_BINARY: พิกเซล ≥ 128 ได้ค่า? → 255 (ขาว) · ต่ำกว่า → 0
  • พิกเซล 200 ผ่าน BINARY (t=128)? → 255
  • THRESH_BINARY_INV ต่างจาก BINARY? → สลับขาว-ดำ (กลับด้าน)
  • THRESH_TRUNC ทำงานยังไง? → ค่าที่เกิน threshold ถูกตัดให้เท่ากับ threshold (ค่าต่ำกว่าคงเดิม)
  • THRESH_TOZERO? → ค่าที่ต่ำกว่า threshold กลายเป็น 0 (เกินคงเดิม)
  • Global threshold มีปัญหาอะไร? → แสงไม่สม่ำเสมอ — ขีดเดียวใช้ไม่ได้
  • Adaptive ต่างจาก Global ยังไง? → คำนวณ threshold แยกเป็นแต่ละพื้นที่ (local จาก neighborhood)
  • ค่า 11 ใน adaptiveThreshold? → blockSize — ขนาด neighborhood 11×11 พิกเซล
  • ค่า 2 (ตัวสุดท้าย) ใน adaptiveThreshold? → ค่าคงที่ C ที่ลบออกจาก threshold ที่คำนวณได้
  • Otsu คืออะไร? → หา threshold อัตโนมัติจาก histogram (แยก 2 กลุ่มได้ดีที่สุด)
  • ใช้ Otsu ใน OpenCV ยังไง? → cv2.THRESH_BINARY + cv2.THRESH_OTSU (ค่าขีดอยู่ใน ret)
  • Erosion มีผลยังไง? → กร่อนขอบวัตถุให้เล็กลง (ลบพิกเซลขอบ) + ลบ noise จุดเล็ก
  • Dilation มีผลยังไง? → ขยายขอบวัตถุให้ใหญ่ขึ้น (เติมรู/ช่องว่างเล็ก)
  • Opening / Closing คือ? → Opening = erode→dilate (ลบจุดเล็ก) · Closing = dilate→erode (ปิดรูเล็ก)
  • findContours ใช้หาอะไร? → ขอบเขต (contour) ของวัตถุในภาพ binary
  • SIFT / SURF / ORB คืออะไร? → Feature Descriptor — อธิบายจุดเด่นของภาพ (จับคู่ภาพ/ตรวจจับวัตถุ)
  • boundingRect คืนค่าอะไร? → (x, y, w, h) — สี่เหลี่ยมครอบวัตถุ
  • Perspective transform ใช้ทำอะไร? → แก้ภาพเอียง/เบี้ยวให้ตรง (สแกนเอกสาร) ด้วย 4 มุม
  • YOLO / SSD / Faster R-CNN คืออะไร? → โมเดล Deep Learning ตรวจจับวัตถุ (class + bounding box)
  • YOLO vs Faster R-CNN? → YOLO เร็ว (one-stage) · Faster R-CNN แม่นสุด (two-stage)
  • CNN ต่างจาก ML ทั่วไป? → CNN เรียนรู้ feature เองจากภาพตรง ๆ (ไม่ต้องออกแบบ feature ด้วยมือ)
