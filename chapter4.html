FUNDAMENTALS

สูตร Filter Response — อ่านทีละตัว

สมการเดียวของทั้งบท — ฟังดูยาว แต่จริง ๆ คือ "คูณทีละช่อง แล้วบวกกัน"

g(x, y) = Σ Σ w(s,t) · f(x+s, y+t)
🎯 g(x,y) = ภาพผลลัพธ์ (output) ที่ตำแหน่ง (x,y)
📥 f(x,y) = ภาพต้นทาง (input) · w(s,t) = ค่าสัมประสิทธิ์ของ kernel/mask (น้ำหนัก)
🔢 (s,t) = ตำแหน่ง offset ใน kernel — เช่น kernel 3×3 มี (s,t) ตั้งแต่ (-1,-1) ถึง (1,1)
📏 a = (m-1)/2, b = (n-1)/2 — ครึ่งหนึ่งของขนาด mask m×n · ใช้ลิมิต Σ จาก s=-a ถึง a และ t=-b ถึง b
🧮 จับมือ เอา kernel วางทับบนภาพ → คูณค่า kernel แต่ละช่องกับพิกเซลที่ซ้อน → รวมทุกช่อง = g(x,y)
จำแบบนี้"คูณทีละช่อง บวกทั้งหมด" = ผลตอบของ linear filter · กึ่งกลางของ mask = ตัวเลขที่เราจะแทนลงในภาพผลลัพธ์

SMOOTHING

Mean vs Median — ต่างกันยังไง?

จำประโยคเดียวจากเอกสาร: Mean = weighted average · Median = sort แล้วเอาค่ากลาง

Mean Filter (Linear)

Pixel neighborhood → Weighted average
ใช้ kernel (เช่น 1/9 ทุกช่อง)
เบลอทั่วทั้งภาพ รวม noise กระจาย

Median Filter (Non-linear)

Pixel neighborhood → Sort values → Middle value
ไม่ต้องใช้ kernel
ค่าผิดปกติสุดขั้ว (salt-pepper) ไม่ชนะ — เก็บขอบได้ดีกว่า

🧮 ตัวอย่าง 9 ค่า: 0,3,5,8,9,12,17,21,255 — Mean = (0+3+5+8+9+12+17+21+255)/9 ≈ 36.7 (จุด 255 ดึงค่าให้สูงผิดเพี้ยน) · Median = 9 (255 ไม่มีผล) → median กัน noise ได้ดีกว่า
Exam Tipข้อสอบชอบถาม "จุด 255 (salt) ตัวไหนทนกว่า?" → Median เพราะใช้ค่ากลาง ไม่ใช่ค่าเฉลี่ย

DIFFERENTIATION

Finite Differences — 3 แบบ

แคลคูลัสแบบปกติใช้ไม่ได้กับข้อมูลไม่ต่อเนื่อง (พิกเซล) — เลยใช้ "ผลต่างจำกัด" วัดการเปลี่ยนแปลงทีละขั้น

Forward [-1 1] ∂f = f(x+1) − f(x)
Backward [1 -1] ∂f = f(x) − f(x−1)
Central ½[-1 0 1] ∂f = ½(f(x+1) − f(x−1))
🧮 จับมือ forward แถวพิกเซล [10, 10, 10, 40] — forward diff: 0, 0, 30 → จุดที่ค่าเปลี่ยน (30) = ตำแหน่งขอบ!
💡 สรุป อนุพันธ์ตอบสนองแรงเฉพาะจุดที่ค่า "เปลี่ยนเร็ว" — นั่นคือสิ่งที่เราเรียกว่า edge

DIFFERENTIATION

Continuous vs Discrete

ทำไมแคลคูลัสปกตินำมาใช้กับภาพตรง ๆ ไม่ได้? เพราะภาพเป็นข้อมูล "จุด ๆ" ไม่ใช่เส้นโค้ง

DIFFERENTIATION

Gradient Operator ∇f

Gradient = เวกเตอร์ที่บอก "ทิศทาง" และ "ความแรง" ของการเปลี่ยน intensity — หัวใจของ edge detection

∇f = [ ∂f/∂x , ∂f/∂y ] = ∂f/∂x · i + ∂f/∂y · j

2 ข้อมูลจาก ∇f

• ทิศทาง — ชี้ไปทางที่ intensity เปลี่ยนเร็วที่สุด
• ขนาด (magnitude) — √(Gx² + Gy²) ความแรงของ edge

Exam TipGradient = first-order derivative — บอกทิศ + ขนาดของ edge
ลองนึกภาพ: เขา (ภาพ) กับ แผนที่ความสูง (gradient)
ขอบ

ตรง "ขอบ" ที่สีเปลี่ยนเร็ว ∇f มีค่ามาก — ตรงพื้นที่สม่ำเสมอ ∇f ≈ 0

EDGE DETECTION

Sobel — ประวัติ + แนวคิด

หนึ่งในตัวตรวจจับขอบที่ดังที่สุด — gradient-based ใช้ kernel 3×3 จำนวนเต็ม 2 ตัว

ที่มา

• พัฒนาโดย Irwin Sobel และ Gary Feldman
• ที่ Stanford Artificial Intelligence Laboratory (SAIL)
• ปลายทศวรรษ 1960

Sobel = Differentiation + Smoothing

kernel ของ Sobel คือการ รวมอนุพันธ์ (differentiation) กับการ ถ่วงน้ำหนัก (smoothing) — จึงทน noise ได้ดีกว่าอนุพันธ์ล้วน ๆ

ผลลัพธ์

ที่แต่ละจุดได้ gradient vector หรือขนาด (norm) ของมัน — แล้ว threshold เพื่อแยกขอบจริง

SHARPENING

Laplacian — Second-order Derivative

ต่อจาก Gradient (อันดับ 1) — Laplacian คืออนุพันธ์อันดับ 2 ใช้หา edge และ sharpening

∇²f = ∂²f/∂x² + ∂²f/∂y²

Discrete Form — จับมือ

∂²f/∂x² = f(x+1,y) + f(x-1,y) − 2f(x,y)
∂²f/∂y² = f(x,y+1) + f(x,y-1) − 2f(x,y)
→ ∇²f = f(x+1,y)+f(x-1,y)+f(x,y+1)+f(x,y-1) − 4f(x,y)

อ่านง่าย ๆ: "ผลรวมเพื่อนบ้าน 4 ทิศ − 4×จุดกลาง"

ใช้ทำอะไร

• หา Edges (จุดที่ค่ากระโดด)
• Sharpening: g = f − ∇²f (ลบ Laplacian ออกจากภาพเดิม)

ถ้า center ใหญ่เกินไป (>5) = sharpening แรงเกิน → ขอบจะเกิด overshoot, halo (ขอบขาวเกิน/ดำเกินรอบเส้น)

Exam Tipcenter=4 → 0 Laplacian · center=5 → 1× sharpen · center>5 → sharpen แรงขึ้น + halo — จำตัวเลข 4/5 ไว้ให้ขึ้นใจ

SHARPENING

โค้ด Laplacian จริง (Python + OpenCV)

จากเอกสาร: แปลงภาพด้วย Laplacian แล้วบวกกลับเพื่อ sharpening

# วิธีที่ 1: kernel 4-neighbor เอง kernel = np.array([ [0,1,0], [1,-4,1], [0,1,0] ], np.float32) dst = cv2.filter2D(img, -1, kernel) # วิธีที่ 2: ใช้ฟังก์ชันสำเร็จรูป dst = cv2.Laplacian(img, -1, ksize=3) # Sharpening: ภาพเดิม + Laplacian im2 = img + dst

3 ภาพที่เห็น

• img — ภาพต้นทาง
• dst — Laplacian (เห็นแต่ขอบ)
• im2 = img + dst — sharpened (ภาพเดิม + ขอบ)

จำง่าย ๆLaplacian เก็บ "ขอบ" ไว้ → เอามาบวกกลับกับภาพเดิม = ภาพคมขึ้น

SHARPENING

First vs Second Order — เลือกใช้อันไหน?

Gradient (อันดับ 1) vs Laplacian (อันดับ 2) — ต่างกันที่ "ความไว" ต่อการเปลี่ยนของ intensity

First-order: Gradient / Sobel

• ตอบสนองเมื่อค่าเปลี่ยนเร็ว (ความชัน)
• ใช้หา ความแรง + ทิศทาง ของ edge
• ทน noise ได้ดีกว่า (Sobel มี smoothing)

Second-order: Laplacian

• ตอบสนองเมื่อค่ามีจุดเปลี่ยน (crossing) — ไวต่อ noise มากกว่า
• ใช้กับ sharpening โดยตรง (g = f − ∇²f)
• Flat region → 0 · ที่ edge → ไม่เท่า 0

จำแบบนี้1st order (Sobel/Gradient) = วัดความชัน เหมาะหา edge · 2nd order (Laplacian) = วัดจุดเปลี่ยน เหมาะ sharpen แต่ไวต่อ noise
