WHAT IS OPENCV?

OpenCV คืออะไร?

ก่อนเขียนโค้ด ต้องรู้ก่อนว่าเรากำลังใช้ "อะไร" — OpenCV คือไลบรารี (library) สำหรับงานประมวลผลภาพและ Computer Vision

OpenCV = Open Source Computer Vision Library

คืออะไร

ชุดคำสั่งสำเร็จรูป (library) สำหรับอ่าน/แก้ไข/วิเคราะห์ภาพและวิดีโอ

ใช้ทำอะไร

ตรวจจับใบหน้า/วัตถุ · OCR อ่านตัวหนังสือ · นับสิ่งของ · ตามวัตถุ · AR

ฟรี และเปิดเผย

Open Source — ใช้ได้ทั้งงานวิจัยและเชิงพาณิชย์ ไม่ต้องจ่ายเงิน

ที่มาและภาษา

  • ฟังก์ชันเยอะมาก — กว่า 2,500 อัลกอริทึมสำเร็จรูป ไม่ต้องเขียนเอง

FUNDAMENTALS

ภาพใน OpenCV คือ NumPy Array

ภาพที่อ่านเข้ามาแล้ว = ตารางตัวเลข (array) — ตัวเลขแต่ละช่องคือค่าพิกเซล

ภาพเล็ก 3×4 (grayscale) มองเป็นตารางตัวเลข
x=0x=1x=2x=3
y=0104090160
y=12060120200
y=23080150240

ยิ่งเลขมากยิ่งสว่าง — ภาพ = เมทริกซ์ตัวเลขนี้เอง

ทำไมต้อง NumPy?

คำนวณทั้ง array ได้เร็วมาก (vectorized) — ปรับความสว่างทั้งภาพ = บวกเลขทั้งตารางครั้งเดียว

ภาพสี = array 3 มิติ

(แถว, คอลัมน์, ช่องสี) — แต่ละจุดมีค่า 3 ตัว (B, G, R) แทนที่จะเป็น 1 ตัว

จำแบบนี้img = ตารางตัวเลข (NumPy array) · แก้พิกเซล = แก้ตัวเลขในตาราง

READ IMAGE

อ่านภาพ — cv2.imread()

คำสั่งแรกของทุกโปรเจกต์ — เปิดไฟล์ภาพเข้ามาเป็น NumPy array

โค้ดพื้นฐาน 
import cv2

img = cv2.imread("image.jpg")   # อ่านภาพเข้ามา
print(img)                       # ดูตัวเลขพิกเซล
print(type(img))                 # <class 'numpy.ndarray'>
1cv2.imread(path) — path คือที่อยู่ไฟล์ภาพ
2ได้ผลลัพธ์เป็น array เก็บในตัวแปร img
3ถ้า path ผิดจะได้ None — เช็คเสมอว่าไม่ว่าง

อ่านเป็น grayscale ได้ด้วย

img = cv2.imread("image.jpg", 0) — อ่านตรง ๆ เป็นภาพเทา 1 ช่อง (ขาว-ดำ)

ข้อควรจำ

นามสกุลไฟล์ (jpg/png) ไม่สำคัญตอนอ่าน — OpenCV เดารูปแบบจากเนื้อไฟล์ให้อัตโนมัติ

เทคนิคสอบอ่านภาพ = cv2.imread() · แสดงภาพ = cv2.imshow() — อย่าสลับกัน!

IMAGE PROPERTIES

img.shape — (Height, Width, Channels)

ถามขนาดภาพด้วย img.shape — คำตอบเรียง: ความสูง, ความกว้าง, จำนวนช่อง

ตัวอย่าง: ภาพ 640×480 สี
(480Height · แถว · y
640Width · คอลัมน์ · x
3)Channels · ช่องสี
img = cv2.imread("image.jpg")   # 640 x 480
print(img.shape)
# (480, 640, 3)

กับดักที่เจอบ่อยที่สุด

Height (480) มาก่อน Width (640) — เพราะใน array แถว (y) มาก่อนคอลัมน์ (x) เสมอ

แยกอ่านทีละค่า

h, w = img.shape[:2] (grayscale)
h, w, c = img.shape (ภาพสี)

เทคนิคสอบshape = (Height, Width, Channels) — ตัวแรกคือ แถว (y) เสมอ!

IMAGE PROPERTIES

img.dtype — uint8

dtype = ชนิดข้อมูลของพิกเซล — ภาพปกติเป็น uint8 = เลขเต็ม 0–255

เช็คชนิดข้อมูล 
print(img.dtype)
# uint8
uunsigned = ไม่มีค่าลบ → เริ่มที่ 0
int88 บิต → ค่าสูงสุด 2^8−1 = 255
รวมuint8 = 0 ถึง 255 — พอดีกับระดับเทาของภาพ

ระวังเวลาคำนวณ

uint8 เก็บเลข 0–255 เท่านั้น — ถ้าคำนวณแล้วเกิน 255 จะ wrap (วนกลับ) หรือถูก clip ต้องแปลงเป็น float ก่อนแล้วค่อยกลับ

ชนิดอื่น ๆ

float32/float64 ใช้ตอนคำนวณ (เช่น แบ่ง 255) · uint16 สำหรับภาพ 16 บิต

เทคนิคสอบuint8 = 0–255 = 8 บิตไม่มีเครื่องหมาย — dtype ของภาพปกติ

DISPLAY · OPENCV

แสดงภาพ — cv2.imshow()

วิธีที่ 1: หน้าต่างของ OpenCV เอง — ต้องใช้ 3 คำสั่งคู่กัน

โค้ดที่ถูกต้อง 
cv2.imshow("Image", img)   # 1. เปิดหน้าต่างชื่อ Image
cv2.waitKey(0)             # 2. รอจนกว่าจะกดปุ่ม
cv2.destroyAllWindows()    # 3. ปิดหน้าต่างทั้งหมด
1imshow(ชื่อ, ภาพ) — เปิดหน้าต่าง
2waitKey(0) — ค้างหน้าต่างไว้ รอคีย์บอร์ด
3destroyAllWindows() — เคลียร์หน้าต่างหลังเลิกใช้

ลืม waitKey = หน้าต่างกะพริบแล้วปิด

โปรแกรมจบทันที → หน้าต่างปิดตาม — imshow ต้องคู่กับ waitKey เสมอ

waitKey(5000) = รอ 5 วินาที

ใส่ตัวเลขเป็นมิลลิวินาที — waitKey(0) คือรอไม่จำกัดเวลา

ไม่สะดวกใช้หน้าต่าง?ถ้าใช้ Jupyter/Colab ให้ข้ามไปวิธี Matplotlib ในสไลด์ถัดไป

DISPLAY · MATPLOTLIB

แสดงภาพแบบที่ 2 — Matplotlib

วิธีที่ 2: แสดงในกรอบพล็อตของ Matplotlib — นิยมใช้ใน Jupyter/Colab

โค้ดพื้นฐาน 
import matplotlib.pyplot as plt

plt.imshow(img, cmap="gray")   # แสดงภาพ (grayscale ใช้ cmap="gray")
plt.show()                      # วาดออกจอ
cmap ที่มีgray · hot · viridis · jet · plasma — ไว้เปลี่ยนโทนสีของภาพเทา

ภาพสี = ต้องแปลงก่อน!

Matplotlib คิดว่าภาพเป็น RGB แต่ OpenCV ส่งมาเป็น BGR → สีเพี้ยน ต้อง cvtColor ก่อน (สไลด์ 12)

ข้อดี

โชว์หลายภาพในหน้ากระดาษเดียว + วาดกราฟกำกับ (histogram, title, axis) ได้ด้วย

เทคนิคสอบimshow แบบ OpenCV ใช้ cv2. · แบบ Matplotlib ใช้ plt. — และ plt ต้องคู่กับ plt.show()

MATPLOTLIB · LAYOUT

จัดหน้าต่างพล็อต — subplot · title · colorbar

โชว์ภาพหลายภาพในรูปเดียว และใส่ป้ายกำกับให้อ่านง่าย

โค้ด: 2 ภาพในแถวเดียว 
plt.figure(figsize=(8, 6))     # ขนาดรูป
plt.subplot(1, 2, 1)            # แถว 1, คอลัมน์ 2, ช่องที่ 1
plt.imshow(img1, cmap="gray")
plt.title("Original")           # ใส่ชื่อ

plt.subplot(1, 2, 2)            # ช่องที่ 2
plt.imshow(img2, cmap="gray")
plt.title("Processed")
plt.show()

อ่าน subplot(1, 2, 1)

(จำนวนแถว, จำนวนคอลัมน์, ตำแหน่ง) — 1 แถว 2 คอลัมน์ ช่องแรก = ด้านซ้าย

ป้ายกำกับที่ใช้บ่อย

plt.title() ชื่อเรื่อง · plt.xlabel()/ylabel() แกน · plt.colorbar() แถบสีบอกค่า

เคล็ดลับวางภาพก่อน-หลัง (original vs processed) ไว้ข้างกัน — ดูผลต่างชัดทันที

MATPLOTLIB · EXTRAS

พล็อตเสริม — hist · plot · text · axis

เครื่องมือเล็ก ๆ ที่ใช้ประกอบการวิเคราะห์ภาพ

โค้ดรวมของฟังก์ชันยอดนิยม 
plt.hist(img.ravel(), bins=256)     # histogram ของค่าพิกเซล
plt.plot(100, 200, "ro")            # จุดแดงที่ (x=100, y=200)
plt.text(100, 100, "Pixel")         # เขียนข้อความบนรูป
plt.xlim(100, 300)                   # ซูมแกน x
plt.ylim(300, 100)                   # ซูมแกน y (กลับหัวได้)
plt.grid()                           # ตารางกริด
plt.axis("off")                     # ซ่อนแกน
plt.colorbar()                       # แถบสี
histนับจำนวนพิกเซลแต่ละระดับ 0–255 — ดูความสว่าง/คอนทราสต์
plot/textวาดจุด/ข้อความกำกับบนภาพ
xlim/ylimซูมช่วงที่สนใจ (หมายเหตุ: ใส่ plt.ylim(300, 100) = กลับแกน)

COLOR ORDER

BGR vs RGB — กับดักสีสลับ

OpenCV เก็บช่องสีเรียง BGR แต่ Matplotlib/ภาพทั่วไปเรียง RGB — เรื่องนี้สอบติดชัวร์

พิกเซลเดียวกัน อ่าน 2 แบบ 
pixel = img[100, 200]
print(pixel)
# [ 50 120 200 ]
OpenCV (BGR)B = 50 · G = 120 · R = 200 → ภาพออกโทนแดง
Matplotlib (RGB)R = 50 · G = 120 · B = 200 → ภาพออกโทนน้ำเงิน
ผลสีแดงกับน้ำเงินสลับกัน — ภาพผิดเพี้ยน

ทำไม OpenCV ใช้ BGR?

มรดกจากยุคแรกของ C/C++ และฮาร์ดแวร์กล้อง — OpenCV เลยเรียง BGR มาจนถึงทุกวันนี้

ดูยังไงว่าสีสลับ?

ท้องฟ้าควรเป็นฟ้าแต่กลายเป็นส้ม/แดง = อาการคลาสสิกของ BGR แสดงเป็น RGB

เทคนิคสอบBGR = OpenCV · RGB = Matplotlib/ปกติ · ไม่แปลง = สีเพี้ยน

COLOR CONVERSION

แปลงสี — cv2.cvtColor()

วิธีแก้สีสลับ: แปลง BGR → RGB ก่อนแสดงด้วย Matplotlib

โค้ดที่ต้องจำ 
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
plt.imshow(img_rgb)
plt.show()
flag อื่น ๆCOLOR_BGR2GRAY (เทา) · COLOR_RGB2BGR (กลับทาง) · COLOR_BGR2HSV · COLOR_BGR2LAB

อ่านชื่อ flag

COLOR_A2B = แปลงจาก A เป็น B — BGR2RGB คือ BGR → RGB

สลับด้วย slicing ก็ได้

img_rgb = img[:, :, ::-1] — กลับลำดับช่องสุดท้าย (เทียบเท่า cvtColor สำหรับ BGR↔RGB)

เทคนิคสอบก่อน plt.imshow ภาพสี → ต้อง cvtColor(img, cv2.COLOR_BGR2RGB) เสมอ

PIXEL ACCESS

เข้าถึงพิกเซล — img[y, x]

กฎเหล็กของ OpenCV: y (แถว) มาก่อน x (คอลัมน์) เสมอ — ต่างจากคณิตศาสตร์ที่ใช้ (x, y)

ตัวอย่าง: พิกเซลแถว 100 คอลัมน์ 200 
pixel = img[100, 200]   # y=100, x=200
print(pixel)             # [ 50 120 200 ] → BGR

ช่องฟ้า = (y=2, x=2) — y คือแถว (ลงมา) x คือคอลัมน์ (ไปขวา)

กับดักที่พบบ่อย

เคยชินจากคณิต (x, y) → เขียน img[x, y] → ได้ตำแหน่งคนละจุด! จำให้ขึ้นใจ: img[แถว, คอลัมน์]

ผลลัพธ์เป็น array 3 ตัว

ภาพสี: [B, G, R] · ภาพเทา: ค่าเดียว เช่น img[100, 200] = 120

เทคนิคสอบพิกเซล = img[y, x] — y = แถว (row) · x = คอลัมน์ (column)

CHANNELS

แยก Channel — b, g, r = img[y, x]

ดึงช่องสีแต่ละช่องของพิกเซลออกมา — ดัชนี 0 = B · 1 = G · 2 = R

วิธีที่ 1: destructure 
b, g, r = img[100, 200]
print(b, g, r)   # 50 120 200
วิธีที่ 2: ระบุดัชนี 
b = img[100, 200, 0]   # ช่อง 0 = Blue
r = img[100, 200, 2]   # ช่อง 2 = Red

แผนผังช่องสี

0 · B
1 · G
2 · R

จำจาก BGR: 0=B, 1=G, 2=R

นำไปใช้ดึงช่องสีเดียวทั้งภาพ: blue = img[:, :, 0] — ไว้ทำ mask/แยกวัตถุด้วยสี

PIXEL WRITE

เปลี่ยนค่าพิกเซล — img[y, x] = [B, G, R]

กำหนดค่าใหม่ให้พิกเซล — จำลำดับ BGR ให้แม่น (แดง = [0, 0, 255] ไม่ใช่ [255, 0, 0]!)

โค้ด: เปลี่ยนพิกเซล (100, 200) เป็นแดง 
img[100, 200] = [0, 0, 255]   # B=0, G=0, R=255
1สีแดงใน RGB = [255, 0, 0]
2แต่ OpenCV เรียง BGR → สลับเป็น [0, 0, 255]
3แทนค่าลงพิกเซล: img[100, 200] = [0, 0, 255]

สีที่ใช้บ่อย (BGR)

แดง [0,0,255]
เขียว [0,255,0]
น้ำเงิน [255,0,0]
ขาว [255,255,255]
ดำ [0,0,0]
เทคนิคสอบแดงใน OpenCV = [0, 0, 255] (BGR!) — สอบติดประจำ

REGION WRITE

เปลี่ยนทั้งโซน — img[y1:y2, x1:x2]

กำหนดค่าทีละพิกเซลช้าเกินไป — ใช้ slicing เปลี่ยนทั้งบล็อกในครั้งเดียว

โค้ด: ย้อมสีแดงทั้งสี่เหลี่ยม 
# y = 100–200, x = 100–300
img[100:200, 100:300] = [0, 0, 255]

# ตรวจ: พิกเซลกลางโซน
print(img[150, 200])   # [0 0 255]
หมายเหตุy1:y2 ไม่รวม y2 — 100:200 ครอบแถว 100–199

ใช้ทำอะไร?

ปิดบังใบหน้า/ทะเบียน (privacy), ใส่ watermark สี่เหลี่ยม, ทดสอบ mask — พื้นฐานก่อนเรียน ROI

ความหมายของช่วง

img[100:200, 100:300] = แถว 100–199, คอลัมน์ 100–299 — เริ่ม 100 จนถึงก่อน 200

เทคนิคสอบช่วงสุดท้ายไม่รวมค่า — เหมือน Python slicing ทั่วไป

ROI

ROI คืออะไร — Region Of Interest

ROI = บริเวณที่เราสนใจในภาพ — ตัดเฉพาะส่วนนั้นมา ไปประมวลผลต่อ

ตัวอย่าง: สนใจแค่ป้ายทะเบียนรถ
ROI — ป้ายทะเบียน

ประมวลผลเฉพาะ ROI = เร็วขึ้น แม่นขึ้น ไม่ต้องดูทั้งภาพ

ทำไมต้อง ROI?

1. เร็วขึ้น (คำนวณน้อยลง)
2. แม่นขึ้น (ไม่โดนส่วนอื่นรบกวน)
3. ง่ายต่อการวิเคราะห์เฉพาะจุด

ได้มาอย่างไร?

ลากด้วยมือ, ตรวจจับอัตโนมัติ (เช่น หาใบหน้าก่อน), หรือจากโมเดล — สไลด์ถัดไปคือวิธีตัด

จำแบบนี้ROI = Region Of Interest = บริเวณที่สนใจ = ตัดแล้วประมวลผลเฉพาะส่วน

ROI · CROP

ตัด ROI — roi = img[y1:y2, x1:x2]

ใช้ slicing เดียวกับสไลด์ 16 — แต่คราวนี้ เก็บผลลัพธ์ไว้ใช้ต่อ

โจทย์: y = 100–300, x = 200–500 
roi = img[100:300, 200:500]

# ตรวจขนาด ROI
print(roi.shape)
# (200, 300, 3)
1y1:y2 = 100:300 → สูง 200 แถว
2x1:x2 = 200:500 → กว้าง 300 คอลัมน์
3roi.shape = (200, 300, 3) ✓

อ่านสูตรให้ขาด

img[y1:y2, x1:x2] — y มาก่อน x เสมอ · y1 = แถวเริ่ม · y2 = แถวสุดท้าย (ไม่รวม)

view หรือ copy?

slicing เป็น view — แก้ roi แล้วภาพต้นฉบับเปลี่ยนตาม อยากได้สำเนาใช้ .copy()

เทคนิคสอบroi = img[100:300, 200:500] → y = 100–300, x = 200–500

ROI · SHOW & SAVE

แสดง + บันทึก ROI

ตัดมาแล้ว → แสดงให้ดู และบันทึกลงไฟล์เพื่อใช้ต่อ

แสดง ROI 
cv2.imshow("ROI", roi)
cv2.waitKey(0)
บันทึก ROI 
cv2.imwrite("roi.jpg", roi)
จำนามสกุลไฟล์ (jpg/png/bmp) เป็นตัวกำหนดรูปแบบไฟล์ที่บันทึก

imwrite(path, ภาพ)

อาร์กิวเมนต์แรก = ที่อยู่ไฟล์ใหม่ · ตัวที่สอง = ภาพ (array) ที่จะบันทึก

เช็คผลสำเร็จ

ok = cv2.imwrite(...) — คืน True/False ว่าบันทึกสำเร็จไหม

เทคนิคสอบบันทึก = cv2.imwrite() · อ่าน = cv2.imread() · แสดง = cv2.imshow()

FULL EXAMPLE

รวมโค้ดตัวอย่างเต็ม

ตั้งแต่ต้นจนจบ: อ่านภาพ → ตัด ROI → แสดง → บันทึก — ลองไล่ทีละบรรทัด

โจทย์: ตัดป้ายทะเบียน (y 100–300, x 200–500) ออกจากภาพ 
import cv2

img = cv2.imread("image.jpg")          # 1. อ่านภาพ
print(img.shape)                         # 2. ตรวจขนาด

roi = img[100:300, 200:500]             # 3. ตัด ROI

cv2.imshow("Original", img)             # 4. แสดงภาพเดิม
cv2.imshow("ROI", roi)                  # 5. แสดง ROI
cv2.waitKey(0)                           # 6. รอคีย์บอร์ด
cv2.destroyAllWindows()                  # 7. ปิดหน้าต่าง

cv2.imwrite("roi.jpg", roi)             # 8. บันทึก ROI
1อ่านภาพ → array
2ตัด ROI ด้วย slicing
3แสดง + รอ + ปิด
4บันทึกเป็นไฟล์ใหม่

ROI · APPLICATIONS

ROI ในงานจริง

ROI เป็นขั้นแรกของระบบจริงเกือบทุกระบบ — 3 ตัวอย่างจาก PDF

1. OCR

หาตำแหน่งข้อความ → ตัด ROI → ส่งให้ OCR อ่าน → ได้ตัวหนังสือ

1หาว่าข้อความอยู่ตรงไหน
2ตัด ROI รอบข้อความ
3ส่งเข้าอัลกอริทึม OCR

2. ป้ายทะเบียนรถ

กล้องจับภาพรถ → หา ROI ของป้ายทะเบียน → อ่านตัวเลขป้าย

1หาป้ายทะเบียนในภาพ
2ตัด ROI เฉพาะป้าย
3อ่านตัวเลข (OCR)

3. ตรวจจับใบหน้า

หาใบหน้า → ตัด ROI รอบหน้า → วิเคราะห์/เปรียบเทียบใบหน้า

1detect ใบหน้า (bounding box)
2ตัด ROI รอบใบหน้า
3ส่งเข้าขั้นถัดไป
จำแบบนี้ระบบจริง = หาของ (detect) → ตัด ROI → วิเคราะห์เฉพาะ ROI — ROI ลดงานทั้งการคำนวณและ noise

ROI · PERFORMANCE

ROI ลดงานประมวลผล

ตัวอย่าง: ภาพ Full HD 1920×1080 แต่เราสนใจแค่ 300×300 — ประหยัดขนาดไหน?

คำนวณด้วยเครื่องคิดเลข
1ทั้งภาพ: 1920 × 1080 = 2,073,600 พิกเซล
2ROI: 300 × 300 = 90,000 พิกเซล
3คิดเป็น %: 90,000 ÷ 2,073,600 ≈ 4.3%
4ประมวลผลแค่ 4% ของข้อมูล — เร็ว ~23 เท่า!

ทำไมเร็วขนาดนี้?

งานประมวลผลภาพ (กรอง, หาขอบ, OCR) คิดต่อพิกเซล — พิกเซลน้อย = เวลาน้อยตามสัดส่วน

ได้ความแม่นด้วย

ตัดส่วนที่ไม่เกี่ยวข้องออก → อัลกอริทึมไม่โดนรบกวนจากพื้นหลัง/noise

เทคนิคสอบถ้าถาม % ที่ประมวลผล = พิกเซล ROI ÷ พิกเซลทั้งหมด × 100
